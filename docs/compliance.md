# ルールと注意点(compliance)

> このドキュメントは一般的な注意点の整理であり、法律・規約の最終判断ではありません。
> **規約は更新されます。** 運用を始める前と、3か月に1回は、下の「確認先」の最新版を自分の目で読んでください。分からないときは、投稿しない・公式に問い合わせる、を選びます。

## 1. 広告であることの表記(ステルスマーケティング規制)

2023年10月から、広告であることを隠した宣伝(ステルスマーケティング)は景品表示法の規制対象です。アフィリエイトで報酬を得る投稿は「広告」にあたります。

### すべての広告投稿で守ること
1. **投稿の先頭(1行目)に「【PR】」を入れる。** 「広告」でもかまいません。**末尾のハッシュタグだけ(#PR)や、「続きを読む」を押さないと見えない位置は避けます。**
2. リンクを置くリプライにも「【PR】」と「※広告を含みます」を入れる。
3. プロフィールにも「投稿の一部に楽天アフィリエイト(広告)を含みます」と書く。
4. 広告でない投稿(質問・豆知識・体験談)は、広告のふりをしない。逆に、広告を広告でないように見せない。
5. 下書きツールは広告投稿に【PR】を自動で入れ、抜けていれば警告します。**でも最終確認は人の目でお願いします。**

### 表現の注意
| 避けること | 理由・代わりの書き方 |
|---|---|
| 使っていない商品を「使ってよかった」と書く | 事実と違う口コミ・体験談は誤解を招く。「楽天のレビューを読んだ印象」と書く |
| 「絶対」「必ず治る」「No.1」「最安」など断定・最上級 | 根拠がなければ使わない。「私は〜と感じた」「レビューでは〜が多い」と書く |
| 健康・美容の効果効能 | 薬機法の対象になる。この計画では家電・ガジェット中心で、効能の断定はしない |
| 価格を断定する | 価格・ポイント・在庫は変動する。「◯月◯日時点」と書き、リプライに注意書きを入れる(ツールが自動で入れます) |
| 楽天公式ランキングでないものを「ランキング」と書く | 「レビュー件数が多い順」と正確に書く(ツールのテンプレートは対応済み) |
| 他人の画像・文章のコピー | 無断転載は禁止。画像は自分で撮ったもの、または規約で使用が認められたものだけ |

## 2. 楽天アフィリエイトの規約

最新の内容は必ず公式で確認してください。一般に、次のような点が問題になりやすいです。

- **自分で自分のリンクから購入しない**(自己アフィリエイト)。成果の取り消しや、アカウント停止の対象になりえます。家族・知人に頼んで購入してもらうことも避けます。
- **不正なクリック・購入を誘導しない**(「ここから買って」の過度な強要、クリックだけを求める投稿など)。
- **楽天のロゴ・商品画像・文章の使い方は、規約で決められた範囲で。** 商品画像をAPIから取得して載せる場合も、利用条件を確認する。この計画の下書きツールは、画像は使わず文章とリンクのみです。
- **価格・ポイント倍率・キャンペーン情報は、取得時点で変わる。** 古い情報を載せたままにしない。
- **APIの利用規約を守る。** アプリケーションID・アクセスキー・アフィリエイトIDは他人に教えない、GitHubなど公開の場所に書かない。アクセス回数の制限を守る(ツールは1秒に1回までに制限しています)。
- **成果の対象になる条件(有効期間、対象外の商品・サービス)は変わる。** 管理画面で確認する。
- 自分の報酬額・成果の詳細な数字をSNSで公開する場合は、規約で制限がないか確認する。

## 3. Threads(Meta)の利用規約・コミュニティガイドライン

- Threadsの利用規約、Instagramの利用規約、Metaのコミュニティ規定(スパム・誤解を招く行為・不正なエンゲージメントの禁止など)に従う。
- **投稿は自動化しない。** この計画では、下書きの生成は自動でも、投稿は自分の手で(またはThreadsの標準の予約投稿機能で)行います。ログインの代行や非公式なツールによる自動投稿は使いません。
- 複数アカウントを作って同じ投稿をするのはやめる(1アカウントで運用)。
- フォロワーやいいねを買わない。「相互フォロー」の過度な依頼もしない。
- 他の人のコメント・DMを、許可なく宣伝に使わない。

## 4. スパムと見なされないために

| やること | 目安 |
|---|---|
| 投稿頻度 | 1日1本まで(2026-10-03 から毎日投稿)。**広告投稿は1日1本・週5本まで** |
| 広告と広告なしの割合 | 広告投稿は全体の6割までを目安に、非広告投稿を混ぜる(10月は約4割、11月は約6割) |
| 同じ商品・同じ文章 | 同じ商品の再投稿は最低でも30日あける。文章を使い回さない(ツールは同じ商品を避けますが、文面は自分の言葉に書き換える) |
| リンクだけの投稿 | しない。理由・条件・注意点のある文章にする |
| 他人の投稿への返信 | 宣伝リンクを他人のスレッドに貼らない |
| ハッシュタグ | 付けるなら1〜3個。関係のないタグを大量に付けない |
| 反応が悪くても | 投稿数を急に増やして取り戻そうとしない。型・内容を見直す |

## 5. 投稿前の最終チェックリスト(毎回)

- [ ] 広告投稿の先頭に【PR】があり、リプライにも【PR】と広告である旨がある
- [ ] 《 》の書き換え箇所が残っていない
- [ ] 使っていない商品を「使った」と書いていない
- [ ] 価格・在庫を商品ページで確認し、「◯月◯日時点」と書いた
- [ ] 断定・最上級・効能の表現がない
- [ ] 500文字以内に収まっている
- [ ] 最近30日以内に同じ商品を投稿していない
- [ ] 自分のアフィリエイトリンクを自分でクリック・購入していない
