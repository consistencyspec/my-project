# 投稿設計(content-plan)

## 1. 基本ルール

- **10/3から毎日1本**。10月は広告が週3本前後+広告なし週4本前後、11月からは広告約4本+広告なし約3本/週。土曜は「作業日」で、週2時間でその週分をまとめて準備・予約します(`docs/strategy.md` の新計画)。
- 1か月目(10/2〜10/31)は **30本**(広告あり12本、広告なし18本)。2か月目(11月)は **30本**(広告あり18本、広告なし12本)。
- **広告ありの投稿は全体の6割以下**にします(読まれにくさ・スパム判定を避けるため)。
- **広告ありの投稿は、必ず先頭に【PR】を入れます。** リンクはリプライ欄に置き、リプライにも【PR】を入れます(`docs/compliance.md`)。
- Threads の1投稿は**500文字以内**。テンプレートは本文・リプライとも500文字以内に収まるように作ってあります(《 》を自分の言葉に置き換えた後も超えないか確認してください)。
- 《 》で囲んだ部分は **あなた自身の言葉に置き換える場所** です。置き換えずに投稿しないでください。
- **使っていない商品を「使った」と書かない。** 使っていないときは「楽天のレビューを読んだ印象」など、事実のとおりに書きます。
- 同じ商品の重複投稿はしません(ツールが自動で避けます)。

## 2. 投稿の型(13種類)

| No. | 型 | ねらい | 広告 | 目安の効果 |
|---:|---|---|---|---|
| 1 | 悩み解決型 | 悩みに共感し、1つの商品で解決策を示す | あり | クリック・購入に近い |
| 2 | 比較型 | 3商品を並べて選び方を示す | あり | 保存・クリックされやすい |
| 3 | レビュー型 | 口コミ(または自分の使用感)を要約する | あり | 信頼づくり |
| 4 | ランキング型 | レビュー件数順TOP3(楽天公式ランキングではない) | あり | 保存されやすい |
| 5 | セール・イベント型 | 楽天のセール前にチェックしたい1品 | あり | 購入率が上がりやすい |
| 6 | コスパ型 | 「◯円以内ならこれ」 | あり | クリックされやすい |
| 7 | 失敗回避型 | 買う前の確認ポイント+該当商品 | あり | 信頼づくり・保存 |
| 8 | 使用シーン型 | 使う場面を具体的に描く | あり | 共感 |
| 9 | ギフト・季節型 | 贈り物・季節の悩みに合わせる | あり | 12月に強い |
| 10 | 質問・アンケート型 | 質問でリプライを集める(フォロワー・交流づくり) | なし | 表示回数・交流 |
| 11 | 豆知識型 | 役立つ知識を共有する(フォロワーづくり) | なし | 保存・フォロー |
| 12 | 体験談・ストーリー型 | 自分の経験で親近感をつくる | なし | フォロー・信頼 |
| 13 | 旅行プラン型 | 旅行プランと楽天トラベルを紹介(10/30にテスト) | あり | 高単価 |

**広告なしの投稿(10・11・12)を混ぜる理由:** 広告ばかりの投稿は読まれにくく、スパムと見なされる恐れもあります。フォロワーと交流を増やす投稿を約3割入れます。

## 4. 各型の投稿テンプレート

`scripts/generate_drafts.py` が、商品情報を自動で当てはめて下書きを作ります。手で書くときも同じ形を使えます。`《 》` は自分の言葉に置き換えます。「【PR】」は広告投稿の先頭に必須です。

> **リンクの置き方:** 本文にはリンクを入れず、**リプライ(本文への返信)にリンクを置く**形にしています。リプライにも【PR】と広告である旨を入れます。本文だけにリンクを入れる方が反応が良い場合もあるので、1か月目に両方試して比較してもかまいません(その場合も【PR】は本文の先頭に)。

### 型1 悩み解決型(広告あり)
本文:
```text
【PR】《悩み。例: 在宅で肩がこる》、ありませんか?

《その悩みが起きる場面を1行で》

私ならまずこれを試します👇
《商品名》 / 約《価格》円 / ★《評価》(《件数》件)

選ぶ理由: 《あなたの言葉で。例: 軽さと価格のバランスがいい》

リンクはリプ欄に置いておきます。
```
リプライ:
```text
【PR】リンクはこちら
《商品名》
《アフィリエイトURL》
(《月/日》時点の情報)
※広告を含みます。価格・在庫・ポイントは変動します。購入前に商品ページでご確認ください。
```

### 型2 比較型(広告あり)
```text
【PR】《ジャンル》3つを比べてみました

1. 《商品名》 / 約《価格》円 / ★《評価》(《件数》件)
2. 《商品名》 / 約《価格》円 / ★《評価》(《件数》件)
3. 《商品名》 / 約《価格》円 / ★《評価》(《件数》件)

選び方の目安
・《こだわる人: どれ》
・《コスパ重視: どれ》

※レビュー数・評価は楽天市場の表示(《月/日》時点)。使用感ではありません。
リンクはリプ欄です。
```
リプライ: 型1と同じ形で、3商品のリンクを番号つきで並べる。

### 型3 レビュー型(広告あり)
```text
【PR】《使ったことがある場合のみ使用感を書く / 使っていない場合は『楽天のレビューから見た印象』と明記》

《商品名》 / 約《価格》円 / ★《評価》(《件数》件)

良い口コミで多いのは: 《レビューを自分で読んで要約》
気になる口コミ: 《低評価の内容も1つ紹介》

向いている人: 《》
リンクはリプ欄です。
```

### 型4 ランキング型(広告あり)
```text
【PR】《ジャンル》レビュー件数が多い順 TOP3(《月/日》時点)

1位 《商品名》 / 約《価格》円 / ★《評価》(《件数》件)
2位 《商品名》 / 約《価格》円 / ★《評価》(《件数》件)
3位 《商品名》 / 約《価格》円 / ★《評価》(《件数》件)

※楽天公式ランキングではなく、検索結果をレビュー件数の多い順に並べたものです。
一言: 《あなたの感想》
リンクはリプ欄です。
```

### 型5 セール・イベント型(広告あり)
```text
【PR】《開催中のセール名。例: 楽天お買い物マラソン》の前にチェックしたい1品

《商品名》 / 約《価格》円 / ★《評価》(《件数》件)

買う前のメモ: 《エントリー必須か・期間・買い回りの条件を公式ページで確認して書く》
セール価格は《終了日》までとは限りません。
リンクはリプ欄です。
```

### 型6 コスパ型(広告あり)
```text
【PR】《予算》円以内で探すなら、これは候補になりそう

《商品名》 / 約《価格》円 / ★《評価》(《件数》件)

コスパが良いと思う点: 《》
もう少し安い選択肢が良い人は: 《別の探し方》
リンクはリプ欄です。
```

### 型7 失敗回避型(広告あり)
```text
【PR】《ジャンル》を買う前に確認したい3つのこと

1. 《サイズ・対応機種など》
2. 《保証・返品条件》
3. 《よくある失敗》

この条件で探すなら、こんな商品があります👇
《商品名》 / 約《価格》円 / ★《評価》(《件数》件)
リンクはリプ欄です。
```

### 型8 使用シーン型(広告あり)
```text
【PR】《場面。例: 朝の支度が5分短くなった/なりそう》

《使うシーンを具体的に2〜3行》

《商品名》 / 約《価格》円 / ★《評価》(《件数》件)

《実際に使っていない場合は『こんな使い方ができそう』と書く》
リンクはリプ欄です。
```

### 型9 ギフト・季節型(広告あり)
```text
【PR】《贈る相手。例: 家電好きの友人》へのギフト、迷っているなら

《商品名》 / 約《価格》円 / ★《評価》(《件数》件)

おすすめの理由: 《》
贈る前の注意: 《サイズ・のし・配送日など》
リンクはリプ欄です。
```

### 型10 質問・アンケート型(広告なし)
```text
《質問。例: 在宅ワークで「買ってよかった!」と思ったものは?》

私は《あなたの答え》です。
みなさんのおすすめ、ぜひ教えてください🙌
```

### 型11 豆知識型(広告なし)
```text
《豆知識のタイトル。例: モバイルバッテリー、飛行機に持ち込めるのは?》

・《ポイント1》
・《ポイント2》
・《ポイント3》

《出典(公式サイトなど)》
```
※事実を書くときは、公式の情報で確認してから書きます。

### 型12 体験談・ストーリー型(広告なし)
```text
《最近の失敗談・発見・買い物のきっかけなど、自分の経験を3〜5行で》

《そこから学んだこと》
```

### 型13 旅行プラン型(広告あり・手動)
本文:
```text
【PR】《行き先》へ《日数》のプラン案

・《移動》
・《泊まる場所の条件。例: 駅近・朝食付き》
```

リプライ:
```text
【PR】《楽天アフィリエイト管理画面で作った 楽天トラベル のリンクを貼る》
※広告を含みます。料金・空室状況は予約ページでご確認ください。
```

## 5. 型の見直し方

毎週の振り返りで `tracking/summarize.py` が型ごとの成績を出し、「増やす / 継続 / やめる」を提案します(3本以上たまってから判定)。手順は `tracking/review-guide.md` を見てください。
