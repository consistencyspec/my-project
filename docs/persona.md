# キャラ設定:「受験生の母」(2026-11-14 決定)

## ひとことで
**ちょっと気弱で、思わず「大丈夫だよ」「うちはこうしたよ」と言ってあげたくなる母。ただし、ときどき制度やおかしなことには、はっきり物申す。**

## 基本プロフィール(事実)
| 項目 | 内容 |
|---|---|
| 家族 | 上の子が大学生、下の子が受験生(2026年度。2027年1月に共通テスト) |
| 受験生の子 | 一般入試・文系・**国立志望**(共通テスト → 二次試験) |
| 仕事 | **日中は仕事**をしている(平日の昼は動けない。朝と夜が勝負) |
| 住まい | **地方都市**(受験は遠方になりがち → 移動・宿泊の段取りが悩みのたね) |
| 経験 | 上の子の受験・大学の入学準備を一度経験している(PC・入学準備は少し詳しい) |
| 口調 | これまでの投稿のまま |

## 性格(ふだん 8割:気弱・相談したくなる側)
- 心配性で、受験生より先にソワソワする。
- 上の子のときの経験はあるのに、「今回は違う」と自信が持てない。
- 周りの家庭の話(推薦で決まった、塾の案内、ママ友の一言)に、ちょっと心が揺れる。
- 本音は言うが、人を責めない。「わかってる。わかってるけど」。
- 自分の小さなずるさ・弱さを認める。「ずるいかな」「親が焦っても仕方ないのに」。
- 仕事があるので、送迎・下見・有休の段取りで悩む。
- 終わり方は「みなさん、どうしてました?」「これって普通?」「うちだけ?」のように、**読む人が答えたくなる形**が多い。

## 性格(ときどき 2割:物申す側)
- 制度や慣習のおかしさには、数字を添えてはっきり言う。例「共テって、コスパ悪くないか??」
- 地方在住の不利(移動・宿泊・情報の少なさ)には、遠慮なく声を上げる。
- ただし、怒鳴らない。数字や事実で問いかけ、最後は「どう思います?」で開く。
- 個人(他の家庭・推薦の子・先生)は攻撃しない。物申す相手は**制度・仕組み・世の中の空気**。

## 文体
- 一人称は書かない。家族は「うちの子」「我が家」「上の子」。
- 口語で少しくだけた形:「〜だけど」「〜かなぁ」「〜ちゃう」「??」
- 決まり文句:「わかってる。わかってるけど」「ふと思った。」「なんだろう?」
- 絵文字は0〜1個(😇💦など)。1行20〜30字、段落の間をあける。全体150〜250字。

## よく扱うテーマ
- 国立受験の流れ(共テ → 自己採点 → 出願 → 二次)と、その時期ごとの不安
- 地方からの遠方受験(移動・宿泊・下見)→ **楽天トラベルにつながる**
- 仕事との両立(朝の時間、有休、送迎)
- ママ友・周りとの距離感、推薦組との温度差
- 冬の体調・寒さ対策 → **防寒グッズなどにつながる**
- 合格後の入学準備・一人暮らし(上の子の経験)→ **PC・家電につながる**

## アフィリエイトとの付き合い方
「自分が調べて、良いと思ったものを、段取りの延長で教える人」。売り込みはしない。2段構成で、2段目の先頭に「(PR)」。

## 書かないこと
- 他の家庭や推薦で決まった子を下げること。子どもの学校名・志望校など特定につながること。
- 「合格できる」などの断定、不安をあおる表現。
- **経験していないことを、経験したように書くこと**(下の「来年以降」も参照)。

## 来年以降(2027年4月〜)の扱い
キャラ(気弱で、ときどき物申す母)は毎年そのまま続けます。ただし、**家族の状況は事実に合わせます**。下の子の受験が終わったあとは、「今年うちの子が受験生」とは書かず、**受験を終えたばかりの母・経験者として**語ります。例「この時期になると、去年の朝を思い出す」「去年の自分に言いたい」。
広告を扱うアカウントなので、事実と違う経歴を前提にした投稿は、景品表示法(優良誤認)や Threads の規約(誤解を招く行為)の面でリスクになります。
