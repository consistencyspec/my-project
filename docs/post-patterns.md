## 共通する特徴
- **トピックは「受験生の母」。** 一般入試の子を持つ母の一人称。
- **1行目が「会話」か「問いかけ」。** 「〜って聞かれた」「〜って聞こえてくる」「え?〜じゃないの?」「〜って、もう取ってる?」「〜って、コスパ悪くないか??」
- **「わかってる。わかってるけど」の本音。** 正しさより、言いにくい気持ちを書く(いいね率が最も高い)。
- **短い行・余白が多い。** 1行20〜30字、4〜6段落。全体で150〜250字ほど。
- **最後は本音か問いかけで終わる。** 「ずるいかな」「ちょっとだけ心がザワつく」「高2のうちに決めた方がいいのかも…」
- **時期にぴったり合っている。** 推薦の合格が出る時期、受験票の公開日、二次試験の宿の予約時期。
- **朝に投稿。**

## 4つの型

### A 本音・葛藤型(いいね・共感が最も多い)
```
《周りの言葉や出来事。例: ママ友に「どこ受けるの?」って聞かれた。》

《相手を責めない一文。例: 悪気がないのはわかってる。》
《わかってるけど、の本音。》

《自分の小さなずるさ・弱さ。例: 受かったら言う。落ちたら言わない。》
《締めの一言。例: ずるいかな。でもそれくらいは許してほしい。》
```

### B 焦り×実用型(表示が最も多い・アフィリエイトにつながる)
```
《今の状況。例: 共テのことで頭いっぱいだけど、ふと思った。》

《実用の問いかけ。例: 二次試験のホテルって、もう取ってる?》

《焦りの理由。例: 結果が出てから…と思ってたら、もう埋まり始めてるって聞いて焦ってる》
```
→ **2段目(返信)**に「(PR)」つきで、役立つ確認ポイントと楽天のリンクを置く。1段目にはリンクを入れない(11/9の実測で、1段目にリンクを入れると表示がほぼゼロ)。

### C 新事実・驚き型
```
《驚きの一言。例: え?共テ会場って毎年固定じゃないの?》

《公式情報の事実と日付。例: 受験票がマイページで見られるのは12月4日から。》
《そこから生まれる親の心配。例: 送迎は何時に出る?下見は行ける?》

《親のソワソワ。》
《カウントダウン。例: 共通テストまであと◯日。》
```
※日付・ルールは、大学入試センターや大学の公式情報で必ず確認する。

### D 数字の問題提起型
```
《ちょっと挑発的な問い。例: 共テって、コスパ悪くないか??》

《公式・信頼できる数字。》
《数字から言えること。》

《親としての迷い。例: 高2のうちに決めた方がいいのかもしれない…。》
```
※数字は出典を確認できるものだけ使う。確認できない数字は書かない。

## 書くときのルール
- 事実(日付・数字・ルール)は公式情報で確認する。確認できないものは書かない。
- 自分の家庭のことは、事実と違うことを書かない。
- 不安をあおらない。他の家庭や推薦で決まった子を下げない。学校名など特定できる情報は書かない。
- 広告は2段目だけ。2段目の先頭に「(PR)」を入れる。効果の断定(「合格できる」など)はしない。
- 共通テスト(令和9年度)は **2027年1月16日(土)・17日(日)**。
