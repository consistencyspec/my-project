# 戦略ドキュメント:Threads × 楽天アフィリエイトで「売上100万円」を目指す

> 最初に正直なことを書きます。
> **「週2時間・フォロワー約70人・3か月」で月間売上100万円に届く可能性は、とても低いです。**
> 理由と、現実的に見込める金額、届くために必要な条件を、このドキュメントの「3. 逆算表」にまとめました。
> このプロジェクトは、100万円を「保証」するものではなく、**100万円に最短で近づくための仕組み**です。

## 0. 前提(2026-10-01 時点)

| 項目 | 内容 |
|---|---|
| 目標 | 3か月後の月(2026年12月)に、楽天アフィリエイト管理画面の「売上金額」(購入金額の合計)を100万円にする。**自分の報酬額ではない** |
| 現在のフォロワー | 約70人 |
| 楽天アフィリエイト | 登録済み |
| 作業時間 | 週2時間(毎週土曜に集中して作業) |
| 開始日 | 2026-10-02(金) |
| 月の区切り | 1か月目=10月、2か月目=11月、3か月目=12月 |

## 1. ジャンル選定(3候補の比較)

| 比較項目 | A. 家電・ガジェット(在宅・暮らしの便利グッズ) | B. 日用品・消耗品(食品・洗剤など) | C. 旅行(楽天トラベル) |
|---|---|---|---|
| 需要の安定性 | ◎ 通年で安定。秋冬は暖房・加湿・年末ギフトで増える | ◎ 最も安定(毎月必ず買う) | △ 季節・連休・景気で大きく変動 |
| 1件あたりの購入金額 | ○ 5,000〜30,000円(複数買いで増える) | × 1,000〜4,000円 | ◎ 20,000〜60,000円 |
| 購入までの距離(買う気になりやすさ) | ○ 比較して買う人が多く、悩み解決型と相性が良い | ◎ 買い慣れており決めやすい | △ 予約までの検討が長い。成約率は低め |
| 初心者がレビュー・比較を書きやすいか | ◎ スペックと口コミで比較できる | △ 差が分かりにくく、投稿が似通う | ○ プラン紹介は書きやすい |
| 楽天の商品検索APIで下書きを自動化できるか | ◎ できる | ◎ できる | × 商品検索APIの対象外(楽天トラベルは別のAPI)。手作業が増える |
| 週2時間で回せるか | ◎ | ◎ | △ プランづくりに時間がかかる |
| 売上100万円に必要な購入件数 | 約100件(平均1万円) | 約290件(平均3,500円) | 約25件(平均4万円) |
| 競合の多さ | △ 多い(差別化は「悩み別」「比較」で) | △ 多い | ○ 個人のプラン提案はまだ余地あり |

### 推奨:A. 家電・ガジェット(在宅・暮らしの便利グッズ)

理由は3つです。

1. **週2時間という制約と、いちばん相性がよい。** 商品検索APIで下書きを自動で作れるため、あなたの作業は「確認して投稿する」だけに近づけられます。Cは自動化できず、時間が足りなくなります。
2. **購入単価と需要のバランスがよい。** Bは件数が多く必要で、Cは成約率が低く季節に左右されます。Aは中間で、平均1万円前後の購入が見込めます。
3. **12月に強い。** 年末のギフト・買い替え需要と、楽天のセール(お買い物マラソンなど)が重なります。

**Cの扱い:** 旅行は購入単価が最も高く魅力があります。そのため、**10月30日に1回だけ「旅行プラン型」をテスト**します(calendar.csv に入れてあります)。反応が良ければ、2か月目以降に週1本まで増やします。反応がなければやめます。

## 2. ターゲット読者と悩み

**ターゲット:** 20〜40代の会社員・在宅ワーカー・一人暮らしの人(性別は問わない)。「買い物で失敗したくないが、調べる時間がない」人。

| 悩み | 欲しいもの | 響く投稿の型 |
|---|---|---|
| 在宅・デスクで肩こり、目の疲れ、散らかる | デスク周りの便利グッズ、モニターライト、ハブ | 悩み解決型、使用シーン型 |
| 家事や朝の支度の時間が足りない | 時短家電、ロボット掃除機、速乾ドライヤー | 比較型、コスパ型 |
| 選択肢が多すぎて選べない | 「結局どれ?」の答え | 比較型、ランキング型 |
| 買って後悔したくない | 買う前の確認ポイント、口コミの要約 | 失敗回避型、レビュー型 |
| 寒さ・乾燥(秋冬) | 電気毛布、加湿器、空気清浄機 | 悩み解決型、ギフト・季節型 |
| セールでどれを買うか迷う | セール前の候補リスト | セール・イベント型 |

**プロフィール(固定)の例:** 「在宅ワーク歴◯年。買って後悔しない家電・ガジェットだけ紹介。投稿の一部に楽天アフィリエイト(広告)を含みます」。広告を利用していることをプロフィールにも書きます(詳しくは `docs/compliance.md`)。

## 3. 月100万円の売上に必要な数字の逆算表

### 3-1. 計算の仕組み

```
売上 = 広告投稿の本数 × 1投稿の表示回数 × リンククリック率 × 購入率 × 平均購入金額
```

- **平均購入金額:** 紹介した商品だけでなく、リンク経由で同時に買われた他の商品も含まれることが多い(有効な範囲や期間は楽天の規約で確認)。ここでは家電・ガジェットで1万円と置く。
- **購入率:** クリックした人のうち、実際に購入した人の割合。目安は1〜3%。
- **リンククリック率:** 表示された回数のうち、リンクがクリックされる割合。目安は0.5〜1.2%。

> ⚠️ これらは**一般的な目安をもとにした仮の数字**です。あなたのアカウントの実際の数字ではありません。**1か月目に実測して、このシートの数字を置き換えること**が最初の仕事です(`tracking/` の集計に実測値が出ます)。

### 3-2. 目標から逆算(標準シナリオ)

| 項目 | ガジェット(推奨) | 日用品 | 旅行 |
|---|---:|---:|---:|
| 目標の売上金額 | 1,000,000円 | 1,000,000円 | 1,000,000円 |
| 平均購入金額(仮) | 10,000円 | 3,500円 | 40,000円 |
| 必要な購入件数 | **100件** | 約290件 | 25件 |
| 購入率(仮) | 2% | 2.5% | 1% |
| 必要なクリック数 | **5,000回** | 約11,400回 | 2,500回 |
| リンククリック率(仮) | 0.8% | 0.8% | 0.8% |
| 必要な表示回数(合計) | **約62.5万回/月** | 約143万回/月 | 約31万回/月 |
| 広告投稿 月16本の場合、1投稿あたり | **約3.9万回** | 約8.9万回 | 約2万回 |

### 3-3. いまの自分(フォロワー70人)との差

フォロワー70人では、1投稿の表示回数は**100〜400回程度**が現実的です(フォロワー以外にも届く投稿が出れば増えます)。必要な「1投稿あたり約3.9万回」とは、**100倍前後の開きがあります**。

### 3-4. 3か月後(12月)に見込める売上(3シナリオ)

| | 保守 | 標準 | 楽観 |
|---|---:|---:|---:|
| 広告投稿(月) | 14本 | 16本 | 16本 |
| 1投稿の表示回数(仮) | 150 | 400 | 1,500 |
| リンククリック率 | 0.5% | 0.8% | 1.2% |
| 購入率 | 1.5% | 2% | 3% |
| 平均購入金額 | 7,000円 | 10,000円 | 12,000円 |
| クリック数/月 | 約10回 | 約51回 | 約288回 |
| 購入件数/月 | 約0.2件 | 約1件 | 約9件 |
| **12月の売上金額** | **約1,000円** | **約1万円** | **約10万円** |

### 3-5. 正直な評価

- **「週2時間で3か月・売上100万円」は、現実的ではありません。** 楽観シナリオでも10万円前後で、100万円はその約10倍です。
- 100万円に届くのは、**1本の投稿が大きく拡散した場合(数万〜十万回以上表示)**など、運に左右される場合です。狙って再現できる前提では計画しません。
- 作業時間を増やしても、**100万円までの距離は縮まりにくい**です。ボトルネックは作業時間ではなく「表示回数(=フォロワーと拡散)」だからです。
- 週2時間は、**「下書きの作成・集計を自動化して、確認と投稿に集中する」**運用なら十分です。伸びない期間でも赤字にならない(広告費ゼロ)点は強みです。

### 3-6. 100万円に届くために必要な条件

| 条件 | 目安 |
|---|---|
| **期間** | 標準シナリオ(約1万円)から、毎月 +60% で伸び続けて **約10か月**、+40% なら **約13か月**。**12〜18か月が現実的な目安**(成長が続く前提で、保証はない) |
| **表示回数** | 広告投稿1本あたり平均 **約4万回**(旅行中心なら約2万回)。フォロワーが **数千〜1万人規模** になるか、拡散する投稿を継続的に出す必要がある |
| **作業時間** | 週2時間は「運用」には足りるが、「フォロワーを増やす活動」(他の人の投稿への返信、交流、動画・画像づくり)には足りない。**週5〜7時間** に増やせれば伸びる速度は上がる(それでも3か月で100万円は保証できない) |
| **購入単価** | 旅行や高額家電(1件3万円以上)に寄せると、必要な購入件数は減る |
| **セール活用** | 楽天のセール期間は購入率が上がりやすい。12月はセールとギフトが重なる |

### 3-7. このプロジェクトの「通過点」(目標の置き方)

| 月 | 位置づけ | 売上金額の通過点(自己ルール) | 見るべき数字 |
|---|---|---:|---|
| 10月(1か月目) | 土台づくりと検証 | 1万円(未達でもOK) | 1投稿の表示回数、クリック数、どの型が反応するか |
| 11月(2か月目) | 伸びた型を強化 | 5万円 | 反応の良い型のクリック率、フォロワーの増え方 |
| 12月(3か月目) | 100万円に向けて拡大 | 100万円(ストレッチ目標) | 最終的な到達額。届かなかった場合は、このドキュメントの3-6に沿って期間を延長 |

通過点は `tracking/config.json` にあり、書き換えられます。**12月に100万円に届かなかった場合は、失敗ではなく「期間を延長して継続するか判断する」タイミング**として扱います。

## 4. 3か月のロードマップ(各週2時間以内)

毎週土曜の朝10時に自動レポートが届きます。土曜の作業セッション(2時間)は `docs/weekly-routine.md` の時間配分で行います。**ここでは「その週の重点」だけ書きます。**

> **時間が足りない週に減らすもの(順番):** ①Threadsインサイトの転記 → ②非広告の投稿を手書きから「質問型」だけに → ③下書きの修正を全部やらず広告投稿だけ → ④それでも足りなければ投稿本数を週4→週3に。**売上に直結する「広告投稿の確認と投稿」と「CSV取り込み」は減らさない。**

### 1か月目(10月):土台づくりと検証

| 週(土曜) | 重点(各週2時間以内) | 目安時間 |
|---|---|---|
| 第1週(10/3) | **初期設定。** `.env` 作成、デモで動作確認、実APIで10/4〜10/10分の下書き生成、プロフィールに広告利用を明記、固定投稿(自己紹介)を投稿。10/2(金)の自己紹介は手書きで投稿済みの想定 | 設定60分+下書き確認40分+予約投稿20分 |
| 第2週(10/10) | **初回レポートを読み、記録の流れを確認。** 先週の投稿をposted に更新、楽天CSVを初めて取り込み(見出し確認)、来週分の下書き生成・確認・予約 | 120分 |
| 第3週(10/17) | **型の検証。** 悩み解決・比較・レビュー・ランキングの反応(表示・いいね・クリック)を見比べる。来週分を作成 | 120分 |
| 第4週(10/24) | **3週間分の暫定判定。** 反応のない型を1つ候補にあげる。セール・イベント型の準備(楽天のセール日程を公式で確認) | 120分 |
| 第5週(10/31) | **1か月目の振り返り。** 月次集計、型の判定、11月の calendar.csv を作成(反応の良い型を多めに) | 振り返り40分+11月分カレンダー30分+下書き50分 |

### 2か月目(11月):伸びた型を強化

| 週(土曜) | 重点(各週2時間以内) | 目安時間 |
|---|---|---|
| 第6週(11/7) | 反応の良い型を週2本に増やす。反応のない型を外す。旅行プラン型の結果を判定 | 120分 |
| 第7週(11/14) | 売れた商品の「同じ悩みの別商品」を投稿(同じ商品の繰り返しはしない)。投稿の書き出し1行目を2パターン試す | 120分 |
| 第8週(11/21) | 11月のセール(ブラックフライデー前)に向けた投稿を準備。比較型・ギフト型を強化 | 120分 |
| 第9週(11/28) | 2か月目の振り返り。12月の calendar.csv を作成。年末ギフト・買い替え需要の商品を選定 | 振り返り40分+12月分カレンダー30分+下書き50分 |

### 3か月目(12月):100万円に向けて拡大

| 週(土曜) | 重点(各週2時間以内) | 目安時間 |
|---|---|---|
| 第10週(12/5) | 年末ギフト特集を開始。伸びた型・商品ジャンルを中心に週5本まで増やす(スパムにならない範囲で。商品は重複させない) | 120分 |
| 第11週(12/12) | 高単価商品(1.5万円以上)の比較・レビュー型を増やす。クリック率の低い投稿の書き出しを直す | 120分 |
| 第12週(12/19) | 年末セール・クリスマス前の駆け込み需要投稿。在庫・配送日の注意を明記 | 120分 |
| 第13週(12/26) | **最終判定。** 12月の売上と、3-6の条件に照らして、継続・期間延長・方針変更を決める(目標に届かなくても、データは次の期間に使える) | 振り返り60分+次期計画60分 |

## 5. 成功・撤退の判断(目安)

- **続ける:** 12月までに売上が毎月増えている、またはクリック数が増えている。
- **見直す:** 2か月続けて表示回数が1投稿100回未満 → ジャンルや書き出しの方針を見直す。
- **やめる/縮小:** 3か月続けてクリックがほぼゼロ → 運用時間を減らして方針を見直す(広告費はかかっていないので、損失は作業時間だけ)。
