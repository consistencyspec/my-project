# 週ごとの作業手順書(毎週2時間)

**作業日は毎週土曜日。** 朝10時に自動レポートが届くので、それを読んでから始めます。時間は合計120分です。

> 毎週の流れ: **土曜10時にレポートが届く → 楽天CSVを置く(次の週のレポートがより正確に) → 来週分の下書き確認 → 予約投稿 → 記録**

## 時間配分(合計120分)

| 時間 | 作業 | やること | 使うもの |
|---:|---|---|---|
| 10分 | ① レポートを読む | 土曜10時に届く週次レポートで、先週の売上・クリック・型ごとの判定を見る | レポート(`tracking/reports/`) |
| 15分 | ② 成果データを取り込む | 楽天アフィリエイト管理画面から先週分のCSVをダウンロードし、`tracking/imports/` に置いて取り込みコマンドを実行 | `tracking/import_report.py` |
| 10分 | ③ 投稿の記録を更新 | 先週投稿したものの `status` を `posted` に、`posted_date` を入れる。見送ったものは `skipped` | `tracking/posts.csv` |
| 15分 | ④ 振り返りと方針決め | レポートの「増やす / やめる」を見て、来週の型を calendar.csv で調整(1〜2か所だけ) | `scripts/calendar.csv` |
| 5分 | ⑤ 来週分の下書きを作る | コマンドを1回実行(下記) | `scripts/generate_drafts.py` |
| 40分 | ⑥ 下書きを確認・修正 | 約4本。1本あたり約10分。《 》を自分の言葉に置き換える。商品ページで価格・在庫を確認。`docs/compliance.md` のチェックリストを確認 | `output/drafts_日付.md` |
| 25分 | ⑦ 投稿・予約 | Threadsで投稿または予約投稿(広告投稿は本文→リプライの順)。広告なし投稿は手書きで1〜2分ずつ | Threads アプリ |
| 0〜 | 余り時間 | 予備(15分程度)。最初の数週間はここが操作の習熟に使われる | |

合計: 10+15+10+15+5+40+25 = **120分**(実際には余りが出ない前提で組んであります)。

## 手順の詳細

### ② 成果データの取り込み(手入力を減らす中心の作業)
1. 楽天アフィリエイトの管理画面にログインし、「成果(レポート)」から**直近1〜2週間分のCSV(商品別・日別があればそちら)**をダウンロードする。
2. ファイルを `tracking/imports/` に置く(名前は日付がわかる名前に。例: `2026-10-10.csv`)。
3. ターミナルで実行:
   ```
   python3 tracking/import_report.py tracking/imports/2026-10-10.csv
   ```
4. 「◯行を取り込みました」と出れば完了。同じ期間を重ねて取り込んでも二重計上されません。
5. 「売上金額の列が見つかりません」と出たときは、`python3 tracking/import_report.py ファイル名 --show-columns` で見出しを確認し、`tracking/column_map.json` に自分のCSVの見出し名を足す(初回だけ)。

### ⑤ 来週分の下書きの作り方
```
python3 scripts/generate_drafts.py --start 2026-10-10 --days 7
```
(開始日は「次に投稿する日」。→ `output/drafts_2026-10-10.md` が作られ、`tracking/posts.csv` に下書きが追記されます。)

### ⑥ 確認のコツ
- 警告(⚠️)が出ている箇所から直す。
- 《 》は全部書き換える。思いつかないときは、その型の投稿を見送り、calendar.csv で別の型に差し替える。
- 気になる商品は、商品ページを開いて「在庫あり」「価格」「レビューの内容」を見る。
- 少しでも不安な投稿は、投稿しない(次週に回す)。

### ⑦ 投稿のコツ
- Threadsの予約投稿が使えるときは、土曜にまとめて予約する。使えない場合は、月・水・金・日の都合のよい時間に1〜2分で投稿する(1投稿につき手作業は数分)。
- 投稿時間は固定せず、1か月目は朝(7〜9時)と夜(20〜22時)を交互に試し、反応をレポートで比べる。

## 時間が足りないとき(減らす順番)

1. Threadsの「表示回数」を `posts.csv` に転記する作業を、上位・下位の3本だけにする。
2. 広告なし投稿は「質問型」だけにする(10・11・12のうち、手間のかかる豆知識と体験談を減らす)。
3. 下書きの修正は、広告投稿だけにする。
4. それでも足りなければ、投稿を週4本→週3本にする。

**減らしてはいけないもの:** 広告投稿の確認(【PR】と《 》のチェック)、楽天CSVの取り込み。

## 毎週の完了チェック

- [ ] 土曜のレポートを読んだ
- [ ] 楽天CSVを取り込んだ
- [ ] 先週の投稿の status を更新した
- [ ] 来週の下書きを確認し、予約・投稿の準備ができた
- [ ] `git` で変更を保存した(README の「保存のしかた」参照)
