# SNS投稿の下書き

毎朝7時ごろ(日本時間)、2つのサイト(furusato-yosan.com・tanka-erabu.com)の最新の数字から、Threads と X の投稿の下書きがこのフォルダに自動で保存されます(`日付.md`)。

## 使い方
1. その日のファイル(例: `2026-11-06.md`)を開く。スマホなら GitHub アプリでも読めます
2. 投稿したいものを選び、`《 》` を自分の言葉に直す
3. リンク先を開いて、数字が同じか確かめる
4. **自分の手で**投稿する(自動では投稿しません)

## 目安
- **Threads**:1日1件まで。今のフォロワーの方向けの投稿が中心なので、混ぜすぎないように
- **X**:1日1〜3件。数字の速報として使う
- 1行目の「(PR)」と、最後の「※広告を含みます」は消さない

## 手で作るとき
```
python3 sites/social/make_posts.py
```
