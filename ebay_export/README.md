# eBay 輸出:相場調査と利益計算

日本のプライズ品・一番くじ・ガチャなどを eBay で売るための、**相場調査**と**利益計算**のツールです。
**eBay公式のAPIだけを使います。** メルカリなどを自動で読み取ることはしません(メルカリは、レポートのリンクから自分で開いて確認します)。
Python だけで動きます(pip のインストールは不要)。

## 調べ方の流れ(おすすめ)

**「eBayで売れているもの」から逆算して、「日本でいくらまでなら仕入れてよいか」を出す**順番です。

1. **相場調査**(`ebay_research.py`):キーワードごとに、eBay(アメリカ)の出品中の価格と、日本からの出品数(=ライバル数)を調べます。その価格で売れたときの **「仕入れ上限(円)」** を計算します。
2. **売れた実績を確認**:レポートの「Terapeak」リンク(eBay公式・無料)で、過去90日に**実際に売れた件数と価格**を確認します。出品中の価格は「売れる価格」とは限らないためです。
3. **仕入れ**:「メルカリ(安い順)」リンクで、仕入れ上限より安い出品を探します。
4. **最終確認**:候補が見つかったら、`profit.py` で送料などを入れて、利益を正確に計算します。

## 1. 準備(最初の1回だけ)

このフォルダ(`ebay_research.py` `profit.py` `config.py` `keywords.txt` `items_sample.csv` `env.txt` `README.md`)を、ダウンロードの中の `ebay` というフォルダに入れます。

## 2. eBay API のキーを入れる(相場調査を使う場合)

1. https://developer.ebay.com/ で「Join」(無料)を押し、いつもの eBay アカウントでログインして開発者登録します。
2. 「Application Keys」のページで、**Production**(本番)のキーを作ります(アプリ名は何でもOK)。
3. 表示された **App ID (Client ID)** と **Cert ID (Client Secret)** を、`env.txt` の「ここに〜」と置き換えて保存します。
   - テキストエディットの場合は、メニュー「フォーマット」→「標準テキストにする」にしてから保存してください。
   - キーは人に見せたり、チャットやSNSに貼ったりしないでください。

## 3. 相場調査を実行する

1. `keywords.txt` に、調べたいキーワードを書きます。1行に「eBayで検索する英語 | メルカリで探す日本語」の形です。
   ```
   Ichiban Kuji Last One Prize | 一番くじ ラストワン賞
   ```
2. ターミナルで実行します。
   ```bash
   cd ~/Downloads/ebay
   ```
   ```bash
   python3 ebay_research.py
   ```
3. `output` フォルダの `ebay_research_日時.html` をダブルクリックすると、**仕入れ上限が高い順**の一覧が開きます。

**見るポイント**
- **仕入れ上限(円)**:この金額より安く仕入れられれば、目標の利益が出ます。
- **日本からの出品数**:多いほどライバルが多いです。全体の出品数に比べて日本からが少ないものは、狙い目です。
- **Terapeak**:売れた件数が少ないものは、出品中の価格が高くても売れていません。

## 4. 利益計算

**1件だけ計算する**
```bash
python3 profit.py
```
仕入れ値・販売価格・送料などを聞かれるので、順に入力します。利益の内訳と、「この販売価格なら仕入れはいくら以下に」「この仕入れ値なら販売価格はいくら以上に」が表示されます。

**まとめて計算する**
`items_sample.csv` と同じ形の CSV を作り(Excel や Numbers で「CSV」形式で保存)、次のように実行します。
```bash
python3 profit.py items_sample.csv
```
結果は `output/profit_日時.csv` に出ます。

## 5. 設定(config.py)

手数料・送料・為替は、**2026年11月時点の目安**です。10年のご経験で把握されている実際の数字に合わせて直してください。

| 項目 | 初期値 | 内容 |
|---|---|---|
| `USD_JPY` | 150 | 為替。少し円高側にしておくと安全です |
| `FINAL_VALUE_FEE_RATE` | 13.25% | 落札手数料(カテゴリにより異なる) |
| `INTERNATIONAL_FEE_RATE` | 1.65% | 海外取引手数料 |
| `PAYOUT_FX_COST_RATE` | 2% | ドル→円の為替コスト |
| `PROMOTED_AD_RATE` | 0% | 広告を使う場合の率 |
| `DEFAULT_SHIPPING_COST_JPY` | 2,500円 | 発送の実費 |
| `US_DDP` / `US_TARIFF_RATE` | する / 15% | アメリカ向けの関税を出品者が負担する場合 |
| `MIN_PROFIT_JPY` / `MIN_MARGIN` | 1,500円 / 20% | 目標の利益 |

## 6. 注意点

- **アメリカの関税**:2025年8月から、少額の荷物にも関税がかかるようになりました。関税を出品者が負担する(DDP)と、利益が大きく減ります(初期設定では販売価格の15%で計算)。発送方法ごとの最新の条件を確認してください。
- **出品中の価格 ≠ 売れる価格**:必ず Terapeak で売れた実績を確認してください。
- **偽物**:プライズフィギュアには偽物が出回っています。仕入れ時に確認してください。
- 調査で使うのは eBay 公式の Browse API だけです(1日5,000回まで無料。このツールは1キーワードあたり2回使います)。
