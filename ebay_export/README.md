# eBay 輸出:相場調査と利益計算

日本のプライズ品・一番くじ・ガチャなどを eBay で売るための、**相場調査**と**利益計算**のツールです。
**eBay公式のAPIだけを使います。** メルカリなどを自動で読み取ることはしません(メルカリは、レポートのリンクから自分で開いて確認します)。
Python だけで動きます(pip のインストールは不要)。

## 調べ方の流れ(おすすめ)

**「eBayで売れているもの」から逆算して、「日本でいくらまでなら仕入れてよいか」を出す**順番です。

1. **相場調査**(`ebay_research.py`):キーワードごとに、eBay(アメリカ)の出品中の価格と、日本からの出品数(=ライバル数)を調べます。その価格で売れたときの **「仕入れ上限(円)」** を計算します。
2. **売れた実績を確認**:レポートの「Terapeak」リンク(eBay公式・無料)で、過去90日に**実際に売れた件数と価格**を確認します。出品中の価格は「売れる価格」とは限らないためです。
3. **仕入れ**:「メルカリ(安い順)」リンクで、仕入れ上限より安い出品を探します。
4. **最終確認**:候補が見つかったら、`profit.py` で送料などを入れて、利益を正確に計算します。

## 1. 準備(最初の1回だけ)

このフォルダのファイル(`ebay_research.py` `profit.py` `sales_report.py` `config.py` `keywords.txt` `items_sample.csv` `demo_sales.json` `env.txt` `README.md`)を、ダウンロードの中の `ebay` というフォルダに入れます。

## 2. eBay API のキーを入れる(相場調査を使う場合)

1. https://developer.ebay.com/ で「Join」(無料)を押し、いつもの eBay アカウントでログインして開発者登録します。
2. 「Application Keys」のページで、**Production**(本番)のキーを作ります(アプリ名は何でもOK)。
3. 表示された **App ID (Client ID)** と **Cert ID (Client Secret)** を、`env.txt` の「ここに〜」と置き換えて保存します。
   - テキストエディットの場合は、メニュー「フォーマット」→「標準テキストにする」にしてから保存してください。
   - キーは人に見せたり、チャットやSNSに貼ったりしないでください。

## 3. 相場調査を実行する

1. `keywords.txt` に、調べたいキーワードを書きます。1行に「eBayで検索する英語 | メルカリで探す日本語」の形です。
   ```
   Ichiban Kuji Last One Prize | 一番くじ ラストワン賞
   ```
2. ターミナルで実行します。
   ```bash
   cd ~/Downloads/ebay
   ```
   ```bash
   python3 ebay_research.py
   ```
3. `output` フォルダの `ebay_research_日時.html` をダブルクリックすると、**仕入れ上限が高い順**の一覧が開きます。

**見るポイント**
- **仕入れ上限(円)**:この金額より安く仕入れられれば、目標の利益が出ます。
- **日本からの出品数**:多いほどライバルが多いです。全体の出品数に比べて日本からが少ないものは、狙い目です。
- **Terapeak**:売れた件数が少ないものは、出品中の価格が高くても売れていません。

## 4. 利益計算

**1件だけ計算する**
```bash
python3 profit.py
```
仕入れ値・販売価格・送料などを聞かれるので、順に入力します。利益の内訳と、「この販売価格なら仕入れはいくら以下に」「この仕入れ値なら販売価格はいくら以上に」が表示されます。

**まとめて計算する**
`items_sample.csv` と同じ形の CSV を作り(Excel や Numbers で「CSV」形式で保存)、次のように実行します。
```bash
python3 profit.py items_sample.csv
```
結果は `output/profit_日時.csv` に出ます。

## 5. 設定(config.py)

手数料・送料・為替は、**2026年11月時点の目安**です。10年のご経験で把握されている実際の数字に合わせて直してください。

| 項目 | 初期値 | 内容 |
|---|---|---|
| `USD_JPY` | 150 | 為替。少し円高側にしておくと安全です |
| `FINAL_VALUE_FEE_RATE` | 13.25% | 落札手数料(カテゴリにより異なる) |
| `INTERNATIONAL_FEE_RATE` | 1.65% | 海外取引手数料 |
| `PAYOUT_FX_COST_RATE` | 2% | ドル→円の為替コスト |
| `PROMOTED_AD_RATE` | 0% | 広告を使う場合の率 |
| `DEFAULT_SHIPPING_COST_JPY` | 2,500円 | 発送の実費 |
| `US_DDP` / `US_TARIFF_RATE` | する / 15% | アメリカ向けの関税を出品者が負担する場合 |
| `MIN_PROFIT_JPY` / `MIN_MARGIN` | 1,500円 / 20% | 目標の利益 |

## 6. 利益集計(sales_report.py)

eBay の明細から**実際に引かれた手数料と入金額**を注文ごとに取得し、自分で入れた仕入れ値・発送費を引いて、本当の利益を集計します。
グループ別(作品・シリーズ)・月別・国別に、どこで儲かっているかが一覧になります。

### まずはお試し(eBayに接続しません)
```bash
python3 sales_report.py --demo --from 2026-09-01 --to 2026-10-31
```
`output` フォルダの `sales_report_日時.html` を開くと、レポートの見た目が確認できます。

### 準備(最初の1回だけ)
1. developer.ebay.com の「Application Keys」→ Production の「**User Tokens**」を開きます。
2. 「Get a Token from eBay via Your Application」の欄で、**RuName(eBay Redirect URL name)** を作ります(「Add eBay Redirect URL」)。
   - 「Your auth accepted URL」は空欄のままで大丈夫です(eBay標準の完了ページになります)。
3. 作られた RuName(英数字とハイフンの文字列)を、`env.txt` の `EBAY_RUNAME=` の後ろに書いて保存します。
4. ターミナルで次を実行し、表示された手順に従います。
   ```bash
   python3 sales_report.py --login
   ```
   - 表示されたURLをブラウザで開き、eBayにログインして「Agree(同意)」を押します。
   - 完了ページが表示されたら、**アドレスバーのURLをまるごとコピー**して、ターミナルに貼り付けてエンターを押します。
   - 許可は約1年半有効です。切れたら、もう一度 `--login` を実行します。
   - 作られる `token.txt` は、パスワードと同じくらい大事なファイルです。人に渡さないでください。

### 集計する
```bash
python3 sales_report.py
```
(直近90日。期間を決めるときは `--from 2026-10-01 --to 2026-10-31`)

1. 1回目の実行で、`costs.csv` に注文が追加されます(仕入れ値は空欄)。
2. `costs.csv` を Excel / Numbers で開き、次の列を入力して **CSV形式で** 保存します。
   | 列 | 入れるもの |
   |---|---|
   | `buy_jpy` | 仕入れ値(円) |
   | `ship_cost_jpy` | 発送費(円)。eBayのラベルで送った場合は0(明細から自動で引かれます) |
   | `other_jpy` | 関税(DDP)など、その他の費用(円) |
   | `group` | 集計のグループ名。自動で入りますが、自由に書き換えられます |
3. もう一度実行すると、利益が入ったレポートができます。入力済みの行は、次回以降も消えません。

**ポイント**:SKU に仕入れの管理番号を入れて出品していると、costs.csv で商品を探しやすくなります。

### レポートの見方
- **最終利益**:注文ごとの利益の合計から、広告費など注文にひもづかない費用を引いたものです。
- **グループ別**:作品・シリーズごとの利益と利益率。どこに仕入れを集中させるべきかの判断材料になります。グループ分けのルールは `config.py` の `GROUPS` で変えられます。
- **未入力**:仕入れ値が入っていない注文の数です。未入力の分は利益に含まれていません。

### 注意
- 外貨の金額は、`config.py` の `USD_JPY` で円に換算しています。実際の入金額とは少しずれることがあります。
- 1つの注文に複数の商品があるときは、売上と手数料を商品数で等分しています。
- 最初の集計のあとで、数字が Seller Hub の「Payments」の明細と合っているか、一度見比べてください。

## 7. 注意点

- **アメリカの関税**:2025年8月から、少額の荷物にも関税がかかるようになりました。関税を出品者が負担する(DDP)と、利益が大きく減ります(初期設定では販売価格の15%で計算)。発送方法ごとの最新の条件を確認してください。
- **出品中の価格 ≠ 売れる価格**:必ず Terapeak で売れた実績を確認してください。
- **偽物**:プライズフィギュアには偽物が出回っています。仕入れ時に確認してください。
- 調査で使うのは eBay 公式の Browse API だけです(1日5,000回まで無料。このツールは1キーワードあたり2回使います)。

## 8. 日本からの出品の売れ筋を広く調べる(japan_trends.py)

eBay(アメリカ)の主要24カテゴリについて、**日本から出品されている数が多いサブカテゴリ**と、
そこで**日本の出品者の出品が何個売れているか(推定販売数)**を調べ、売れている順に並べます。

```bash
python3 japan_trends.py
```
5〜10分ほどかかります(API を約1,000回使います。上限は1日5,000回)。`output` フォルダに次のファイルができます。
- `japan_trends_日時.html`:サブカテゴリの売れ筋ランキングと、よく売れている日本の出品の上位150件
- `japan_trends_日時.csv` / `japan_bestsellers_日時.csv`:同じ内容の表

**数字の注意**:eBay の API では「売れた履歴」は取れないため、複数個まとめて出品されている商品の「推定販売数」を使っています。
何度も売れている(=仕入れを繰り返せる)分野は見つけやすい一方、1点ものの売れ行きは数えられません。気になった分野は Terapeak で確認してください。
