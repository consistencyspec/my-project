# 楽天 → Amazon(FBA)価格差チェック

楽天市場で安く買えて(ポイント込み)、Amazon で高く売れる商品を探すツールです。
**楽天とAmazonの公式APIだけを使います。** サイトの画面を自動で読み取る「スクレイピング」はしないので、規約違反の心配はありません。

## まずはこう始める(月額0円)

| 段階 | Amazonの出品プラン | このツールの動き方 |
|---|---|---|
| **① はじめ** | **小口出品(月額0円、売れたら1個100円)** | 「手動モード」:楽天の実質仕入れ値と、**Amazonでいくら以上で売れれば利益が出るか(損益分岐の価格)** を一覧にします。Amazonの価格は、無料の「Amazon Seller」アプリでJANを検索して確認します |
| **② 月50個以上売れるようになったら** | 大口出品(月額4,900円) | 「自動モード」:SP-API(Amazon公式API)につなぎ、カート価格・手数料・ランキング・出品制限まで自動で調べます |

月に約49個までは、小口出品のほうが安く済みます(100円 × 49個 = 4,900円)。**売れる見込みが立つまでは小口で始めるので、月額で赤字になることはありません。**
※ 小口出品でも FBA(Amazonの倉庫から発送)は使えます。

## 1. 準備(最初の1回だけ)

1. このフォルダ(`rakuten_amazon.py` `config.py` `env.txt` `jan_list.txt` `README.md`)を、まとめて「ダウンロード」の中の `sedori2` というフォルダに入れます。
2. **追加のインストールは不要です。** Python だけで動きます(pip も Playwright も使いません)。

## 2. 楽天のIDを入れる

1. `env.txt` を「テキストエディット」で開きます。
2. `ここにアプリケーションID` と `ここにアクセスキー` を、楽天ウェブサービスの値に書き換えて保存します(Threadsのプロジェクトで使っているものと同じでOK)。
   - テキストエディットの場合は、メニュー「フォーマット」→「標準テキストにする」にしてから保存してください。
3. **楽天に、このMacの回線を許可させます。** 楽天ウェブサービスのアプリ設定で「許可されたIP」を設定している場合は、自宅の回線のIPアドレスを追加します。IPアドレスは、ターミナルで次を実行するとわかります。
   ```bash
   curl https://ifconfig.me
   ```
   表示された数字(例:`123.45.67.89`)を、楽天ウェブサービスの「アプリ情報の確認」→ アプリの編集 →「許可されたWebサイト/IPリスト」に追加します。

## 3. 実行する

```bash
cd ~/Downloads/sedori2
```
```bash
python3 rakuten_amazon.py
```

5〜10分ほどで終わり、`output` フォルダに2つのファイルができます。

- `rakuten_amazon_日時.html`:ダブルクリックでブラウザが開きます。調べる商品の一覧です。
- `rakuten_amazon_日時.csv`:全件の一覧です。Excel や Numbers で開けます。

## 4. 手動モードでの確認のしかた

1. HTMLの一覧で、**「Amazonで ¥〇〇 以上なら利益」** の金額を見ます。
2. スマホの「Amazon Seller」アプリ(無料、出品者アカウントでログイン)で、商品のJANを検索します。
3. **カート価格が「損益分岐の価格」より高い**なら、仕入れ候補です。アプリで次の点も確認します。
   - 出品制限がないか(「出品許可が必要」と出たら見送り)
   - 手数料と利益(アプリの利益計算)
   - Amazon本体が売っていないか(本体がいると売れにくい)
   - 売れているか(ランキングの数字が小さいほど売れている)
4. 最初は**1〜2個だけ**仕入れて、実際に売れるか試します。

## 5. 設定を変える(config.py)

| 項目 | 内容 |
|---|---|
| `KEYWORDS` | 楽天で探すキーワード。メーカー名で探すとJANが見つかりやすいです |
| `SHOP_CODES` | 丸ごと調べる楽天のショップ |
| `EXTRA_POINT_PERCENT` | SPU・お買い物マラソンなどの上乗せポイント(%)。**お買い物マラソン中に、ここを増やして実行**すると候補が増えます |
| `MIN_PROFIT` / `MIN_ROI` | 候補にする利益の下限(初期値:500円・15%) |
| `NG_WORDS` / `EXCLUDE_BRANDS` | 除外する言葉とブランド |

調べたい商品のJANが決まっているときは、`jan_list.txt` に1行に1つ書いておくと、楽天での最安値も探します。

## 6. 注意点

- **楽天の商品はJANが書かれていないことが多いです。** JANがない商品はAmazonと照合できないので、自動で除外されます(取得した商品の3割ほどが対象になります)。
- **同じJANでも、セット数や容量が違うことがあります。** 購入前に、楽天とAmazonの商品ページを見比べてください。
- **真贋調査に注意してください。** Amazonから仕入れの請求書を求められたとき、楽天の領収書は認められないことがあります。有名ブランド品は避け、最初は少額で試してください。
- 楽天ポイントは現金ではありません。次の仕入れに使う前提で計算しています。
- 利益は目安です。値下がりや売れ残りで、赤字になることもあります。

## 7. 大口出品にしたら(自動モード)

セラーセントラルで SP-API の「開発者登録(自分用アプリ)」をし、発行された値を `env.txt` の `SPAPI_〜` に入れると、自動モードになります。手順はそのときにご案内します。
