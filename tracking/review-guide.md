# 週ごとの振り返り手順(15分)

目的:**うまくいった型を増やし、反応のない型をやめる。** 判断は感覚ではなく、レポートの数字で行います。

## 手順

1. **レポートを開く。** 毎週土曜10時のレポート、または `python3 tracking/summarize.py --today 土曜の日付`
2. **「型ごとの成績」の表を見る。** 判定は自動で出ます。
   | 判定 | 意味 | やること |
   |---|---|---|
   | 増やす(上位) | 売上・クリックが上位 | 来週の calendar.csv で、この型を1本増やす |
   | 継続 | 反応はあるが上位ではない | 書き出し1行目・商品・投稿時間を変えて再挑戦 |
   | やめる/作り直す | 3本以上でクリックも売上もゼロ | calendar.csv から外す、または切り口を作り直す。理由を1行メモ(posts.csv の notes) |
   | 様子見 | まだ3本未満 | 判断しない(データがたまるまで待つ) |
   | 広告なし | 広告なしの型 | 売上ではなく、表示回数・いいね・リプライで判断 |
3. **「増やす」型は、同じ悩み・別の商品で出す。** 同じ商品の繰り返しはしない(スパム対策)。
4. **1か所だけ変える。** 一度に複数を変えると、何が効いたか分からなくなります(書き出し / 商品 / 時間帯 のどれか1つ)。
5. **メモを残す。** `posts.csv` の `notes` に、気づきを1行(例: 「共感の1行目が効いた」)。
6. **月末は月次の振り返り。** 次の月の calendar.csv を作る(反応の良い型を多めに)。

## 判断のルール(目安)

- 判定するのは、**1つの型につき3本以上たまってから**。
- 「売上ゼロ」でも、クリックが出ている型は、書き方を変えれば伸びることがある(まずクリックが出る型を探す)。
- 「クリックなし・表示も少ない」型は、そもそも読まれていないので、書き出しと投稿時間を見直す。
- **12月に100万円に届かなかった場合:** `docs/strategy.md` の3-6に沿って、期間延長・作業時間・ジャンルを見直す。

## 記録の入力を減らすしくみ

| 項目 | 入力方法 |
|---|---|
| 投稿ID・日付・型・商品・価格 | 下書きを作るときに**自動で記録される** |
| クリック数・注文数・売上金額 | **楽天CSVを取り込むだけ**(自動で投稿に紐づけ) |
| 投稿したかどうか | 手入力(`status` と `posted_date` のみ) |
| 表示回数・いいね・リプライ | 手入力(任意。時間がなければ省略可) |

### 成果の紐づけのルール(目安)
商品コード、または商品名の先頭が一致する投稿のうち、成果の日付より前の「一番新しい投稿」に割り当てます。同じ商品を複数回投稿していると新しい方に集まります。**目標の合計金額の集計は、紐づけとは別に、取り込んだ全データから計算されます**(紐づけできなくても合計には含まれます)。
