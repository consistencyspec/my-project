# 新しい回の作り方(新常識クロニクル)

新しいネタは、**新しいセッション**で始めるのがおすすめ。最初にこう頼めば続きから作れる。

> `youtube-gyakuten/NEW_EPISODE.md` を読んで、新常識クロニクルの新しい回「(テーマ。例:お酒は少しなら体にいい？)」を作って

## 0. 準備(セッションごとに1回)
```bash
bash youtube-gyakuten/scripts/setup.sh
```
日本語フォント・ffmpeg・Python の部品が入る(MiniMax の声を使うなら、これだけでよい)。
MiniMax の API キーはクラウド環境(Default)のネットワーク設定に保存してあり、自動で使われる。コードやファイルにキーを書かない。

## 2. 作る手順
1. **年表を作る**:テーマの研究・公的判断を年代順に集め、各出来事を「いい派/悪い派」「種類(15/10/6/3議席)」で分ける。出典(論文・公的発表の URL)を必ず残し、数字は原文で確かめる
2. **研究カードのデータ**:`scripts/egg_war.py` の `EVENTS` と同じ形のリストを、新しい回のファイル(例 `scripts/alcohol_war.py`)に作る。1件=(年, 国, 種類, 見出し, データ3つ, ピクトグラムの関数, 前の議席, 後の議席, 速報の見出し, 出典)
3. **物語の台本**:`scripts/egg_story.py` をコピー(例 `scripts/alcohol_story.py`)して SCENES を書き換える。主な研究は「はじまり → どうやって → 結果 → 研究カード → 議席」の物語、ほかは研究カード1枚。冒頭の番組紹介・ルール説明・エンディングはそのまま使い回す
4. **サムネイル**:`scripts/thumbnail.py` の EPISODES に題名と副題を足す
5. **書き出し**:`.venv/bin/python scripts/<回>_story.py`(声の生成→映像→音声合わせまで自動。`--script` で台本だけ、`--voice` で声と台本だけ)
6. **できるもの**:`output/<回>/…_draft.mp4`、台本 `content/<回>_story.md`、外部用のナレーション原稿 `content/<回>_narration.txt`

## ナレーションの書き方のルール(読み間違い対策・2026-11-23 確認)
- **「いい派」「悪い派」のすぐあとは、必ず「が」「の」「と」にする。** MiniMax は「派」のあとに「、」「。」・数字・「は」が来ると、助詞の「わ」と読んでしまう(音声を文字起こしして確認ずみ)
  - × 「いい派、59議席。」「悪い派65、いい派35。」「いい派は苦しい」「「いい派」、」
  - ○ 「いい派が59議席に。」「悪い派が65、いい派が35。」「いい派の苦しいスタート」「いい派と悪い派の論争」
- かぎかっこで「いい派」を囲まない(「」は読み上げ前に「、」に変わるため)
- 年号は自動で漢数字にして送る(ひらがなの長い数字は読み崩れる)
- **声の自動チェック**(`scripts/voice_check.py`):声を作ったあと Whisper で聞き取り、読み間違い(「潤い」と聞こえる等)・台本にない余計な音・極端に遅い声を見つけたら自動で作り直す。使い方は `scripts/miryokudo_story.py` の main を参照。`.venv/bin/pip install faster-whisper scipy` が必要(入っていなければチェックは飛ばす)
- **読み方の決まり(全回共通)**:「順位」は「じゅんい」。かな・カタカナで送ると「うるおい」と読まれるので、漢字のまま「ランキングの順位」「沖縄の順位」のように前に言葉をつけ、上のチェックで確かめる/「〇位」は かな+い(よんい・じゅうい)/4で終わる年だけは かなで「〜よねん」(2014年=にせんじゅうよねん)/「トップ10」=トップテン/「たった13」は「ことわった」と聞こえやすいので「わずか13」/「18年間で」「18年間の」は「じゅうばち」と聞こえることがあるので、なるべく別の言い方にする

## 3. 公開前のチェック
- 台本の「公開前に原文で確認すること」をすべて確かめる
- 通しで聞いて読み間違いを探し、`MM_DICT` に足して作り直す(作った声は保存されるので、直した場面だけ費用がかかる)
- 医療・健康の回は「心配な方は医師へ」を入れる
- YouTube の「改変または合成されたコンテンツ」は「はい」
- 同じ名前のチャンネルがないか確認する(「新常識クロニクル」)
