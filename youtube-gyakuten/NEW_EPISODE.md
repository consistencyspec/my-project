# 新しい回の作り方(新常識クロニクル)

新しいネタは、**新しいセッション**で始めるのがおすすめ。最初にこう頼めば続きから作れる。

> `youtube-gyakuten/NEW_EPISODE.md` を読んで、新常識クロニクルの新しい回「(テーマ。例:卵は1日1個まで)」を作って

## 0. 準備(セッションごとに1回)
```bash
bash youtube-gyakuten/scripts/setup.sh
```
日本語フォント・ffmpeg・Python の部品が入る(MiniMax の声を使うなら、これだけでよい)。
MiniMax の API キーはクラウド環境(Default)のネットワーク設定に保存してあり、自動で使われる。コードやファイルにキーを書かない。

## 1. 決まっている型(全回共通)
| 項目 | 決まり | 場所 |
|---|---|---|
| 見た目 | 紺の舞台+赤い幕、白い角丸パネル、太いゴシック、丸い線画のピクトグラム。いい派=オレンジ、悪い派=青 | `scripts/frames.py` |
| 動き | パーツが順に出る、席が弾んでひっくり返る、天秤が傾く、過半数が入れ替わると「逆転！」 | `scripts/motion.py` |
| 議席 | 全100議席。公的機関・裁判所の判断15/研究のまとめ10/数十万人の追跡調査6/条件つきの結果3。議席は演出の目安と明記 | ルール説明の場面 |
| タイトル画面・サムネイル | 上に「新常識クロニクル」、大きな題名、副題「『いい派』vs『悪い派』論争の行方」、2つの派のラベル | `scripts/thumbnail.py`(EPISODES に1行足す) |
| 声 | MiniMax speech-2.8-hd、`Japanese_IntellectualSenior`、速さ1.2 | `scripts/narrate.py` |
| 読み方 | 読み間違えやすい語は `MM_DICT` に「元の文字/読み方」で足す。年号と「数+人」は自動 | `scripts/narrate.py` |
| 構成 | 番組紹介(約30秒)→ テーマのつかみ → タイトル → ルール説明 →「それでは、行ってみましょう！」→ 第1話〜 → 最終結果(当選確実は出さない、観察研究の限界)→ まとめ → 次回予告 → エンディング(チャンネル登録・今後の論争) | `scripts/coffee_story.py` の SCENES |
| クイズ | 入れない | |
| 研究 | 研究・公開データの裏付けを必ずつける。英語圏以外(ドイツ・オランダ・チェコ・北欧・日本など)の研究を優先 | |

## 2. 作る手順
1. **年表を作る**:テーマの研究・公的判断を年代順に集め、各出来事を「いい派/悪い派」「種類(15/10/6/3議席)」で分ける。出典(論文・公的発表の URL)を必ず残し、数字は原文で確かめる
2. **研究カードのデータ**:`scripts/coffee_war.py` の `EVENTS` と同じ形のリストを、新しい回のファイル(例 `scripts/egg_war.py`)に作る。1件=(年, 国, 種類, 見出し, データ3つ, ピクトグラムの関数, 前の議席, 後の議席, 速報の見出し, 出典)
3. **物語の台本**:`scripts/coffee_story.py` をコピー(例 `scripts/egg_story.py`)して SCENES を書き換える。主な研究は「はじまり → どうやって → 結果 → 研究カード → 議席」の物語、ほかは研究カード1枚。冒頭の番組紹介・ルール説明・エンディングはそのまま使い回す
4. **サムネイル**:`scripts/thumbnail.py` の EPISODES に題名と副題を足す
5. **書き出し**:`.venv/bin/python scripts/egg_story.py`(声の生成→映像→音声合わせまで自動。`--script` で台本だけ)
6. **できるもの**:`output/<回>/…_draft.mp4`、台本 `content/<回>_story.md`、外部用のナレーション原稿 `content/<回>_narration.txt`

## 3. 公開前のチェック
- 台本の「公開前に原文で確認すること」をすべて確かめる
- 通しで聞いて読み間違いを探し、`MM_DICT` に足して作り直す(作った声は保存されるので、直した場面だけ費用がかかる)
- 医療・健康の回は「心配な方は医師へ」を入れる
- YouTube の「改変または合成されたコンテンツ」は「はい」
- 同じ名前のチャンネルがないか確認する(「新常識クロニクル」)
