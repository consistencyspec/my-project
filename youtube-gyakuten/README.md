# 逆転劇場(YouTube)企画書

作成：2026-11-21 / 状態：**企画案(まだ何も公開していません)**

理不尽な目にあった主人公が、最後に**正当な手段で**逆転する、オリジナルの短編ドラマ(いわゆる「スカッと系」)のチャンネルです。
制作は、スペイン語チャンネル([`youtube-spanish/`](../youtube-spanish/README.md))で作った仕組み(合成音声・字幕つき画面・サムネイル・キャラクター)を使い回す前提です。

---

## 1. 最初に知っておいてほしいこと(正直な見立て)

- **人気ジャンルですが、競合がとても多い**です。漫画動画・ボイスドラマの大手チャンネルが毎日投稿していて、「普通のスカッと話」では埋もれます。
- **AIでの量産は収益化で不利**です。YouTube は 2025年7月から、テンプレートの使い回しや大量生産の動画を「オリジナリティのないコンテンツ(inauthentic content)」として収益化の対象外にする方針をはっきりさせました。スカッと系はこの対象になりやすいジャンルです。
- そのため、この企画は **「切り口を1つにしぼる」+「毎回、自分の声の解説を入れる」** の2つを前提にしています(スペイン語チャンネルと同じ対策です)。
- **週2時間では長い動画を毎週1本作るのは難しい**です。目安は台本1〜1.5時間、絵と音の確認1〜2時間、サムネと概要欄30分で、**1本あたり3〜4時間**。最初は「2週に1本の長い動画+毎週ショート2本」を提案します。

## 2. コンセプト(提案)

**チャンネル名：逆転劇場**
**サブタイトル案：「知ってる人が勝つ」スカッと劇場**

### 切り口：知識で逆転する
主人公は、怒鳴ったり仕返ししたりせず、**実在するルール・制度・記録・証拠**で逆転します。
最後に1〜2分、「今回の逆転に使ったルール」を自分の声で解説します。

| 選んだ理由 | 中身 |
|---|---|
| 差別化 | 「スカッと+役に立つ」は、ただのスカッと話より少ない |
| 収益化対策 | 解説はその回にしかない内容になり、量産判定のリスクを下げられる |
| 広告に強い | 暴力・過激な復讐がないので、広告がつきにくくなる心配が小さい |
| 既存の資産を使える | Threads の「受験生の親」の読者(`docs/persona.md`)と重なる舞台(学校・PTA・義実家・職場)を選べる |

### 舞台(この3つから回す)
1. **学校・受験・PTA**(Threads の読者と同じ。いちばん力を入れる)
2. **職場**(有休・残業代・パワハラ・手柄の横取り)
3. **家族・ご近所**(義実家・相続・騒音・駐車場)

### 見てほしい人
- 30〜50代、子育て中の親(特に母親)。家事や通勤中に「聞き流し」で見る人
- スマホで見る人が中心 → **字幕は大きく、1画面の文字は少なく**

## 3. 動画の形

### 長い動画(8〜12分・2週に1本)
| 時間 | 中身 |
|---|---|
| 0:00〜0:30 | **つかみ**：いちばんスカッとする場面を先に少しだけ見せる(「…その書類、ご存じないんですか?」) |
| 0:30〜3:00 | **理不尽**：主人公がひどい目にあう |
| 3:00〜5:30 | **ため**：さらに追い込まれる。でも主人公は静かに準備している(伏線) |
| 5:30〜8:00 | **逆転**：準備していたルール・証拠で、相手が自分の言葉で自滅する |
| 8:00〜9:00 | **その後**:相手と主人公のその後(やりすぎない) |
| 9:00〜10:30 | **解説(自分の声)**:今回のルールは本当にある?実際に使うときの注意 |
| 最後 | 「あなたならどうした?」でコメントを促す |

### ショート(60秒以内・毎週2本)
- 長い動画の「逆転の場面」だけを切り出す
- または「知ってる人が勝つ」ルール1つを、30秒の寸劇で紹介する

### 見た目
- **紙芝居形式**(静止画のイラスト+合成音声+大きな字幕)。動くアニメは作らない(手間が大きすぎる)
- 登場人物は毎回「主人公・相手・味方」の3〜4人。**同じ絵柄の人物セットを使い回す**(毎回描かない)
- 進行役キャラを1人置く(例：劇場の支配人キャラ)。オラポン君の仕組み(`characters/`)を流用できる

## 4. 作り方(スペイン語チャンネルからの流用)

| 工程 | 使うもの | 新しく作るもの |
|---|---|---|
| 台本 | Claude に下書きを頼む → **自分で必ず直す** | 台本の JSON の形(話者・セリフ・場面・表情) |
| 声 | `say_ja.py`(日本語の合成音声) | 登場人物ごとの声の設定(高さ・速さ)。悪役は `hoarse.py` のしゃがれ声も使える |
| 絵 | 人物セットの画像+背景 | 人物の表情差分(ふつう・怒り・焦り・ドヤ顔)、背景10枚ほど |
| 画面・動画 | `build_video.py` の仕組み | 「場面転換」「つかみ」「解説」の画面 |
| サムネ | `thumbnail.py` | 「相手の驚いた顔+一言」の型 |
| 解説 | `commentary.py`(自分の声を入れる仕組み) | そのまま使える |

**絵について：** AIで作った画像を使う場合も、他の漫画・アニメの絵柄に似せないこと。人物セットは最初に1回だけ作り、ずっと使い回します。

## 5. 守るルール(公開前のチェック)

- [ ] **話はすべてオリジナル**。他チャンネルの話、まとめサイト・掲示板・SNSの投稿、相談サイトの書き込みを元にしない(言い換えも不可)
- [ ] 実在の人物・会社・学校の名前を出さない。冒頭か最後に「この物語はフィクションです」
- [ ] 解説するルール(法律・制度)は、**公式の出典(e-Gov 法令検索・厚生労働省・文部科学省など)で確認**し、概要欄に出典を書く。「必ずこうなる」と言い切らない
- [ ] 特定の性別・年齢・職業・国籍などを、まとめて悪く描かない(悪いのは「その人」)
- [ ] 暴力・脅し・違法な仕返しで逆転させない
- [ ] YouTube のアップロード時に「改変または合成されたコンテンツ」を確認する(合成音声なので、迷ったら「はい」)
- [ ] 音声モデルのクレジット(条件があるもの)を概要欄から消さない

## 6. 最初の10本のネタ(すべてオリジナル案)

| # | 舞台 | あらすじ | 逆転に使うもの |
|---|---|---|---|
| 1 | PTA | 「仕事してる人も役員は絶対」と押しつける会長。主人公は規約を読み込んでいた | PTAは任意加入、規約の決め方 |
| 2 | 受験 | 「模試E判定なんだから受けるだけムダ」と親戚が笑う。合格発表の日に親戚の集まり | (知識回ではなく、努力回。たまに入れる) |
| 3 | 職場 | 「有休は繁忙期に取るな、理由を言え」と上司。主人公は記録を残していた | 有休の時季変更権の条件 |
| 4 | 義実家 | 「長男の嫁なんだから介護して当然、でも相続はなし」 | 特別の寄与(親族の介護の貢献) |
| 5 | ご近所 | 自分の契約駐車場に毎日停める隣人。「空いてるんだからいいでしょ」 | 契約書と管理会社、記録の取り方 |
| 6 | 職場 | 主人公の企画を自分の手柄として発表する先輩 | 日付つきのメール・共有フォルダの履歴 |
| 7 | 学校 | 「うちの子は悪くない」と記録のないまま主張する保護者 | 学校との面談記録、話した内容を残す |
| 8 | 職場 | 「みなし残業だから残業代は出ない」 | 固定残業代を超えた分の支払い |
| 9 | 受験 | 願書の締め切りを勘違いさせようとする同級生の親 | 主人公は公式の要項で確認していた(確認の大切さ) |
| 10 | ママ友 | グループLINEで陰口、主人公をはずそうとする | 言った・言わないを防ぐ記録、相手が自分で墓穴 |

1本目の詳しい台本の骨組みは [`content/ep01_pta.md`](content/ep01_pta.md) にあります。

## 7. 最初の6週間

| 週 | やること | できあがるもの |
|---|---|---|
| 1 | この企画書を読んで、下の「決めてほしいこと」に答える。人物セットと進行役キャラを決める | 方針決定 |
| 2 | 人物セット(4人×表情4つ)・背景・チャンネルアイコンを作る。ep01の台本を直す | 素材一式 |
| 3 | 日本語の紙芝居動画を作る仕組みを用意する(スペイン語版を改造)。ep01 を試作 | ep01 試作版 |
| 4 | ep01 を自分で最後まで見て直す。解説を録音。**公開**。ショート2本 | 1本目公開 |
| 5 | ep03(職場)の台本と動画。ショート2本 | 2本目の準備 |
| 6 | ep03 公開。2本の数字を見て、舞台をしぼるか決める | 振り返り |

### 見る数字(最初の3か月)
| 数字 | 目安 | 低かったら |
|---|---|---|
| クリック率(サムネを見た人のうち押した人) | 4%以上 | サムネとタイトルを変える |
| 最初の30秒で残った人 | 70%以上 | つかみを短く・強くする |
| 平均で見られた割合 | 40%以上 | 「ため」が長すぎないか見直す |
| 解説まで見た人 | 25%以上 | 解説を短く、または物語の途中に入れる |

登録者・収益化(登録者1,000人+総再生4,000時間、またはショートの再生)は、早くても半年〜1年かかる前提で考えてください。保証はできません。

## 8. 決めてほしいこと

1. **切り口**：「知識で逆転」(提案)でいくか、普通のスカッと話にするか
2. **舞台**:学校・受験・PTA を中心にするか(Threads の読者と重ねる)
3. **ペース**：長い動画は2週に1本(提案)でいいか
4. **絵**:AIで作った人物セットを使うか、イラストを外注(ココナラなど)するか
5. **自分の声の解説**:毎回1〜2分、録音できそうか
6. **Threads との関係**:Threads のアカウントで動画を紹介するか、まったく別にするか
