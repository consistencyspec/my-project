## 流れ
| 場面 | 時間 | 中身 |
|---|---|---|
| つかみ | 0:00〜0:30 | 役員会。由美が1枚の紙を出す。「会長、この規約の第5条、読んでいただけますか?」会長の顔が固まる → タイトル |
| 1. 理不尽 | 0:30〜2:30 | 4月の保護者会。会長「仕事してるとか関係ないの。全員1回は役員、それが決まり」。由美は「受験の年なので…」と言うが、みんなの前で「自分勝手」と言われる |
| 2. ため① | 2:30〜4:00 | 平日昼の会議に出られない由美に、会長が「欠席1回ごとに罰金500円」と言い出す。秋山さんも泣いている |
| 3. ため② | 4:00〜5:30 | 由美は家で、入学時にもらった規約を読み返す。「…あれ?」(何に気づいたかは見せない=伏線) |
| 4. 逆転 | 5:30〜8:00 | 臨時の役員会。由美が規約を読み上げる:入会は任意であること/罰金の決まりは規約にない/規約の変更は総会で決めること。会長「前からこうだったのよ!」→ 由美「前から、規約と違うことをしていたんですね」。他の保護者も「実は困ってた」と次々に声を上げる |
| 5. その後 | 8:00〜9:00 | 次の総会で、役員はくじ引き+できる人が手をあげる形に。罰金はなし。会長は「…勉強になったわ」と小さく言う(やりすぎない) |
| 6. 解説(自分の声) | 9:00〜10:30 | ①PTAは法律で入会が義務づけられた団体ではない ②決まりは学校ごとの規約しだいなので、まず自分の学校の規約を読む ③話し合いは感情でなく「規約の何条」で ④話した内容はメモに残す |
| 締め | 10:30〜 | 支配人「知ってる人が勝つ。あなたの学校のPTA、どうでした?コメントで教えてください」 |
