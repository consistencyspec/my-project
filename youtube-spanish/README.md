# スペイン語 中級リスニング（会話・和訳付き）動画づくり

YouTube 向けに、スペイン語の中級リスニング動画（約8〜10分）を作る仕組みです。
台本（JSON）を1つ用意すると、音声・字幕つきの画面・動画・サムネイル・概要欄の文章までまとめて作ります。

## 試作の3本

| # | テーマ | 文法のポイント | 長さ |
|---|---|---|---|
| ep01 | 不動産屋で部屋を探す | 接続法（まだ見つかっていない物の説明） | 9:21 |
| ep02 | レストランで注文の間違いを伝える | 過去未来形でていねいに頼む・現在完了 | 8:00 |
| ep03 | 友達と週末の出来事を話す | 点過去と線過去の使い分け | 8:21 |

会話文はすべてオリジナルです（市販教材の文章は使っていません）。

## 動画の流れ

1. タイトル（レベルと文法のポイント）
2. 1回目：通しで聞く（字幕はスペイン語だけ）
3. 2回目：1文ずつ聞く（ふつうの速さ → ゆっくり、和訳と単語つき）
4. キーフレーズ（7つ、説明つき）
5. 3回目：和訳と単語つきで通しで聞く
6. 4回目：シャドーイング（セリフのあとに、同じ長さの無音の間）
7. 5回目：字幕なしで聞く
8. まとめ

## 作り方

```bash
cd youtube-spanish
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python scripts/build_video.py content/*.json
```

`output/<id>/` に次のファイルができます（GitHub には上げません）。

| ファイル | 中身 |
|---|---|
| `<id>.mp4` | 動画（1920x1080） |
| `thumbnail.png` | サムネイル（1280x720、下の「サムネイル」を参照） |
| `description.txt` | 概要欄（チャプター・台本・和訳・キーフレーズ・クレジット） |
| `review.md` | ネイティブチェック用の台本（修正案を書く欄つき） |
| `commentary_script.md` | 自分の声で録音する解説の原稿の下書き |

動作確認のテスト：`.venv/bin/python -m unittest discover -s tests -v`

## 新しい回を作るとき

`content/` の JSON をコピーして、`id`・タイトル・会話（`lines`）・キーフレーズ（`phrases`）を書き換えます。
各セリフに `vocab`（少し難しめの単語と和訳、3つまで）を入れると、和訳が出る画面の下に「単語」の欄として表示されます。長いセリフは、単語の欄に重ならないように文字が自動で小さくなります。
話し手は男女1人ずつにして、`voice` に `F`（女性）か `M`（男性）を入れてください。
会話は Claude に「中級（B1）、テーマ〇〇、文法〇〇、18行、スペイン語と和訳」のように頼めば作れます。
市販教材の例文や会話をそのまま入力して言い換えさせるのは、著作権の面で避けてください。

## 公開する前に必ずやること

- **ネイティブチェック**：`review.md` をネイティブに見てもらい、不自然な所を直してから作り直す（ココナラなどで依頼できます）
- **音声の確認**：自分で動画を最後まで聞き、読み間違いや変な抑揚がないか確かめる
- **クレジット**：`description.txt` のクレジット欄を消さない（音声モデルの学習データが CC BY 3.0 で、表示が条件です）
- **YouTube の設定**：アップロード時に「改変または合成されたコンテンツ」の項目を確認する。合成音声を使っているので、迷ったら「はい」にしておくのが安全です

## 自分の声の解説を入れる（収益化対策）

YouTube は、テンプレートと合成音声だけで量産した動画を収益化の対象外にすることがあります。
自分の声で1〜2分の解説を入れると、その回にしかない内容になり、このリスクを大きく下げられます。

### 手順
1. 動画を作ると `output/<id>/commentary_script.md`（原稿の下書き）ができる。話す順番と材料が書いてあります
2. スマホのボイスメモなどで1〜2分録音する（m4a・mp3・wav など、どの形式でも可）。上手に話す必要はありません
3. 録音を `commentary/ep01.m4a` のように置く
4. 台本に `commentary` を足す（原稿の下書きの最後に、そのまま使える例があります）

```json
"commentary": {
  "audio": "commentary/ep01.m4a",
  "slides": [
    {"at": 0,  "title": "この回のポイント", "points": ["接続法は「まだ見つかっていない物」に使う"]},
    {"at": 35, "title": "例文で確認", "points": [{"es": "Busco un piso que esté cerca.", "ja": "近くにある部屋を探しています"}]}
  ]
}
```

5. いつもどおり `build_video.py` を実行する

- 解説は「2回目 1文ずつ」の後に入ります。別の場所にしたいときは `"after": "phrases"` のように指定します（`listen1` `line` `phrases` `listen2` `shadow` `listen3`）
- `at` は、録音を聞いたときにスライドを切り替えたい秒数です。省略すると均等に切り替えます
- 録音は、最後の無音を切り、音量を合成音声とそろえてから入れます（頭の無音は、秒数がずれないように残します）
- 録音ファイルが見つからないときは、警告を出して解説なしで作ります
- チャプター（概要欄）とタイトル画面の「この動画の流れ」にも、自動で「解説」が入ります

## ショート動画「こんな時スペイン語でなんて言う？」

日本語の口語やネットの言葉を、スペイン語でどう言うかを紹介する縦長の動画（約20秒）です。長い動画への入口として使います。

| # | お題 | 答え |
|---|---|---|
| s01 | それな | ¡Ya te digo! |
| s02 | やばい | ¡Qué fuerte! / ¡Qué pasada! |
| s03 | 沼る | Me he enganchado. |
| s04 | ネタバレ | ¡No me hagas spoiler! |
| s05 | エモい | ¡Qué nostalgia! |
| s06 | 草（www） | jajaja |

流れ：お題 → 直訳するとこうなる（×） → 自然な言い方（ふつう → ゆっくり） → 2人のやりとり → ひとことメモとフォローの呼びかけ。
画面の下の方（YouTube のボタンや説明文で隠れる範囲）には文字を置きません。

```bash
.venv/bin/python scripts/build_short.py content/shorts/*.json
```

`output/shorts/<id>/` に動画と `description.txt`（タイトル・ハッシュタグ・概要欄）ができます。
新しい回は `content/shorts/` の JSON をコピーして作ります。`literal`（直訳の失敗例）は省略できます。
流行語は旬が短いので、定着した言葉と混ぜて作るのがおすすめです。キャラクターの画像や曲の音源は使わないでください（著作権）。

## サムネイル

AI で作った「文字の入っていない背景画像」に、左側の赤い帯と3つの文字を自動で重ねます。
文字を AI に描かせないので、文字が崩れず、毎回同じ配置にそろいます。

| 位置 | 文字 | どこから来るか |
|---|---|---|
| 上（黄色い下地） | スペイン語 中級リスニング B1 | 台本の `level` |
| 中央（大きく） | 不動産屋／へ行く | 台本の `thumbnail.title`（`\n` で改行の位置を決める） |
| 下（黒い帯） | 会話・和訳・単語付き | 台本の `thumbnail.band` |

### 手順
1. 画像生成 AI で背景を作る。指示の例：
   「横長16:9。スペインの街並みの不動産屋の店先。ヘッドホンをした笑顔の女性が画面の右側にいて、左を指さしている。**画面の左半分は空けておく。文字やロゴは一切入れない**」
   同じ女性を毎回使うと、チャンネルの「顔」になります。
2. 画像を `thumbnails/ep01.jpg` のように置き、台本に `"background": "thumbnails/ep01.jpg"` を足す
3. サムネイルだけ作り直す：`.venv/bin/python scripts/thumbnail.py content/ep01_piso.json`

背景画像がないときは、紺色の無地にスペイン語のタイトルを入れます。
左半分は赤い帯で隠れるので、背景の左側に何が写っていても構いません。
背景の文字などが帯の外にはみ出すときは、台本の `thumbnail` に `"panel_bottom": 0.59` のように足して、帯を右に広げてください（`panel_top` で上側も変えられます）。

太い日本語フォントを使います。Mac・Windows は標準のフォント（ヒラギノ角ゴ W8、游ゴシック Bold など）を自動で探します。
Linux では `sudo apt install fonts-noto-cjk-extra` で入れてください。

## 音声について

今は無料でオフラインの音声合成 Piper を使っています（音声モデル `es_ES-sharvard-medium`、スペインのスペイン語、男女2人）。
品質は「中くらい」で、本物の人の声と比べると機械っぽさが残ります。
反応が良くて本格的に続ける場合は、Google Cloud や Microsoft Azure などの高品質な音声（有料・API キーが必要）への切り替えを検討してください。
`scripts/build_video.py` の `Speaker` クラスを差し替えれば、他は変えずに使えます。
