# 第1話（長尺版）「おはようの、まちがい」 カット割り・絵コンテ

- 長さの目安：本編 約5分 ＋ きょうのスペイン語 約1分半 ＋ 次回予告 ＝ **約7分**
- 1日の流れ：朝起きる → 「おはよう」の間違い → 朝ごはん → ドライブ → 車が故障 → 歩いて帰る
- シリーズのつながり：最後に「パコの修理屋（Taller de Paco）」の看板を見つける → 第2話「修理屋のパコさん」へ
- 声は最後に入れ直す（セリフは仮）

## キーフレーズ（5つ）
| フレーズ | 意味 | 出てくる場面 |
|---|---|---|
| ¡Despierta! | 起きて！ | シーン1：ドローレスがオラポン君を起こす |
| Buenos días | おはよう（día は男性名詞なので buenos） | シーン2：オラポン君が「Buenas días」と間違える |
| Café con leche | カフェオレ | シーン3：朝ごはん |
| ¡Vamos! | さあ、行こう | シーン4：ドライブに出発 |
| ¡Ay, no! | ああ、もう！ | シーン5：車が故障 |

## 画面の大きさ（略号）
- **引き**：場所全体が見える ／ **全身**：人物の頭から足まで ／ **上半身**：胸から上 ／ **アップ**：顔だけ ／ **寄り**：物（時計・食べ物など）を大きく
- カメラ：**固定** ／ **パン**（横に流す）／ **ズームイン・アウト** ／ **揺れ**（驚きや爆発）

## きょうのスペイン語（約90秒）・次回予告
- 5つのフレーズを1つずつ：ふつう → ゆっくり → 言ってみよう（無音）
- 最後にまとめ：5つを続けてもう一度
- つづく：「次回、修理代は、いくらだポン!?」（第2話「修理屋のパコさん」）

## 作る順番の案
1. 背景（寝室・ダイニング・田舎道）と小物
2. 動きの絵（寝る・乗る・歩く・押す・抱く）
3. 動画を作る仕組みに、カメラ（カット割り）と全身の絵を組み込む
4. この絵コンテを台本データ（JSON）にして、仮の声で動画にする
5. 最後に声を入れ直す
