# オラポン君 ペルソナ（人物像）

台本・ショート・アニメで「オラポン君ならどう言う？どう動く？」に迷ったときに読む1枚。
見た目・素材・声の設定は `CHARACTER.md`。シリーズの流れは `../../anime/series.md`。

---

## ひとことで
**「スペイン語が大好きなのに、いつもちょっとだけ間違える、憎めないおじさん」**

視聴者より少しだけ先を歩く「勉強仲間」。先生ではない。
間違えて、笑われて、最後に言えるようになる姿を見せることで、視聴者が「自分も言えそう」と思える役。

## プロフィール
| 項目 | 内容 |
|---|---|
| 名前 | オラポン（本名は誰も知らない。本人いわく「オラポンはオラポンだポン」） |
| 名前の由来 | スペイン語のあいさつ ¡Hola!（オラ）＋ スペイン語で日本は Japón（ハポン）の「ポン」 |
| 年齢 | 40代なかば（本人は「永遠の38歳」と言いはる） |
| 出身 | 日本の東北の町。うれしいと方言がちょっと出る（「オラ」は東北弁の「わたし」でもある） |
| 今の暮らし | スペイン語の国の小さな町。黄色い家「Casa de Olapón」に、妻ドローレス・赤ちゃんベベ・犬ペロと住む |
| 仕事 | 町の小さな日本食堂の店主。ただし店はいつも暇（ドローレスいわく「趣味」） |
| スペイン語歴 | 3年。中級の入り口。単語はたくさん知っているが、性（男性名詞・女性名詞）と動詞の活用でつまずく |
| 好きなもの | チュロス、カフェオレ（café con leche）、昼寝（シエスタ）、ボロ車、ギター（弾けない）、ラテンの歌 |
| 苦手なもの | 巻き舌の rr、早口のセールスマン、お義母さん、ドローレスの「オホホ」、月末 |
| 宝物 | ソンブレロ（小さい。日本のおみやげ屋で買った）、車の屋根の大きなソンブレロ、家族 |
| 口ぐせ | ¡Hola〜ポン!（オラ〜ポン！）／「〜だポン」／正解の「ポン！」／しょんぼりの「ポ〜ン…」 |

## 性格
| いいところ | だめなところ |
|---|---|
| とにかく前向き。間違えても3秒で立ち直る | お調子者。できた瞬間に調子に乗って、また間違える |
| 人なつっこい。知らない人にも、まずスペイン語で話しかける | 見栄っぱり。わからなくても「わかったポン」と言ってしまう |
| 家族が大好き。とくにベベにはデレデレ | 朝が弱い。片付けができない |
| 失敗を笑いに変えられる | お金の計算が苦手（ボロ車の修理代でいつも青ざめる） |
| 一度言えたフレーズは、得意になって何度も使う | 直訳ぐせ。日本語をそのままスペイン語にして変になる |

- 根っこは **「人と話したいから、スペイン語を勉強している」**。テストのためではない
- 落ちこんでも、最後はかならず「もう一回言ってみるポン」と立ち上がる
- 怒らない。からかわれても、ちょっとすねるだけ

## 話し方のルール
- 語尾の「ポン」は **1本（1話）で3〜4回まで**。多いとくどい（過去に7回で不評）
  - 使いどころ：あいさつ「オラ〜ポン！」、正解の「ポン！」、決めぜりふ、最後のひとこと
- 一人称は「ボク」。うれしい時とあせった時だけ、方言の「オラ」が出る
- 相手を呼ぶとき：妻は「ドローレスさん」（ていねい。ちょっとこわいので）、ベベは「ベベちゃん」、犬は「ペロ」
- スペイン語のセリフは短く、はっきり。1回に1フレーズ
- 説明は短く、たとえ話はおなかがすく話（食べ物）が多い
- 悪口・下品なことば・人をばかにすることは言わない

## 間違え方のパターン（ネタ帳）
オラポン君の間違いは、**日本人が本当によくやる間違い**にする。視聴者が「わかる！」と思えるもの。

| パターン | 例 |
|---|---|
| 名詞の性 | Buenas días（正しくは Buenos días。día は男性名詞） |
| 直訳 | 「よろしく」を直訳しようとして固まる |
| 似た単語 | embarazada（妊娠している）を「恥ずかしい」のつもりで使う |
| 活用 | Yo es…（正しくは Yo soy…） |
| ser と estar | Soy cansado（正しくは Estoy cansado） |
| 発音 | pero（でも）と perro（犬）の言い分け。犬のペロが毎回反応する |
| ていねい語 | お義母さんに tú で話してしまう（usted を使うべき） |
| 国のちがい | スペインとメキシコの文化をごちゃまぜにして、ドローレスに直される |

## 家族・まわりとの関係
| 相手 | 関係 |
|---|---|
| ドローレス（妻） | 頭が上がらない。からかわれてばかりだが、心から尊敬している。なぜスペイン語が完璧なのかは知らない（シリーズの謎） |
| ベベ（赤ちゃん） | 宝物。ベベの「はじめての言葉」はスペイン語にしたくて、毎晩こっそり話しかけている（第10話の伏線） |
| ペロ（犬） | 相棒。どちらも臆病だが、ピンチのときは助け合う。ペロの名前は「犬＝perro」をまちがえて付けた |
| 車 | もう一人の家族。ボロボロでも手放さない。名前は「オレ号」（ナンバープレートの OLÉ から） |
| 修理屋パコさん | 第2話から登場。陽気で早口。オラポン君のスペイン語の先生役になっていく |
| お義母さん | 天敵。でも、ていねいなスペイン語を覚えるきっかけになる（第5話） |

## 動画ごとの役割
| 動画 | オラポン君の役 |
|---|---|
| ショート「こんな時スペイン語でなんて言う？」 | 案内役。「きょう覚えたフレーズを、みんなに教えたいポン！」という立場。先生ぶるが、直訳の例でわざと失敗してみせる |
| アニメ「オラポン一家」 | 主人公で、生徒役。毎回まちがえて、からかわれて、最後に言えるようになる |
| 長い動画（会話のリスニング） | 出ない（または、サムネや最後のあいさつだけ）。長い動画は落ち着いた雰囲気を大事にする |

## お決まりの動き
- 正解すると、決め顔（流し目）でバラをくわえる
- 失敗すると、ソンブレロで顔をかくして「ポ〜ン…」
- 調子に乗ると、ポンチョをひるがえして決めポーズ
- ピンチのときは汗が飛び散る（横向きの「がんばる顔」）
- 車が「プスン……ボンッ！」となると、まず車に「大丈夫かポン!?」と話しかける

## シーズン1で、どう成長するか
| 時期 | オラポン君 |
|---|---|
| 第1〜3話 | 間違いだらけ。でもめげない |
| 第4〜6話 | 少し言えるようになり、調子に乗って失敗する。ドローレスの過去が気になりだす |
| 第7〜9話 | 聞き取りで苦戦（早口・聞き返し）。「わからない」と言えるようになるのが成長 |
| 第10話 | ベベのはじめての言葉で、家族の大切さとスペイン語を学ぶ意味をかみしめる |

## セリフの例
| 場面 | セリフ |
|---|---|
| あいさつ | 「オラ〜ポン！ きょうも一緒に、スペイン語を言ってみるポン」 |
| 間違えたとき | 「えっ!? ボク、また間違えたポン…？」 |
| 立ち直るとき | 「よし、もう一回！ ¡Buenos días!」 |
| 正解したとき | 「（決め顔で）……ポン！」 |
| 調子に乗るとき | 「もうスペイン語はカンペキだポン。あしたからボクのことは先生と呼ぶポン」 |
| ドローレスに | 「ド、ドローレスさん、それは誤解だポン…」 |
| ベベに | 「ベベちゃん、言ってごらん、オ・ラ〜」 |
| 最後のあいさつ | 「毎日ひとつずつ、一緒に覚えるポン！」 |

## 書くときに守ること
- **オラポン君を笑うのはいいが、スペイン語を話す人や国を笑いものにしない**。笑いの中心は、いつもオラポン君の勘違い
- ソンブレロやポンチョは「スペイン語圏が大好きな日本人が、形から入っている」という設定。現地の人のまねではない（ドローレスに「それはメキシコの帽子よ」と突っこまれるネタにも使える）
- 正しいスペイン語は、かならず画面に出す。間違いだけで終わらせない
- 実在の人（芸能人など）の口調や声をまねない
- オラポン君が人を傷つけることは言わない。意地悪はドローレス、オラポン君はやられ役
