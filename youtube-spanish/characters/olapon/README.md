## lipsync/ 口パク用
- base_nomouth.svg … 口だけ無い「通常」の顔
- mouth_a / i / u / e / o / n.svg … 口パーツ。base の上に重ねる
- 音との対応：あ段→a、い段→i、う段→u、え段→e、お段→o、ん・無音・ま行/ば行/ぱ行の口を閉じる瞬間→n
- スペイン語の母音も a e i o u の5つなので、そのまま使える
- 簡易版にするなら n（閉）→ e（半開）→ a（開）の3枚で回す
- 目安：1枚あたり2〜4フレーム（30fps）。セリフの最後は必ず n に戻す
