# 自分の声で録音する解説の台本

- 長い動画は1本あたり約1分半です（ふつうの速さで読んだ目安）
- 【 】の部分は、あなた自身の体験や覚え方に置き換えてください。ここがあなたにしか話せない部分で、収益化の審査でも一番の材料になります
- 「▶スライド」はスライドを切り替える目安です。録音したら、実際に話した秒数を台本の `at` に入れてください
- スペイン語は無理にきれいに発音しなくて大丈夫です（このあと音声で何度も流れます）

---

## 長い動画1：不動産屋で部屋を探す（ep01）

▶スライド1「この回のポイント」（0秒）

こんにちは。今回は、スペインの不動産屋さんで部屋を探す会話でした。ここまで2回聞いてもらいましたが、どうでしたか？
今回のポイントは、ルシアの2つ目のセリフです。
「Estoy buscando un piso que esté cerca del centro.」
「中心街の近くにある部屋を探しています」という意味です。
ここで注目してほしいのが、「esté」という形です。普通なら「está」ですよね。でもここでは、接続法の「esté」になっています。

▶スライド2「例文で比べる」（約25秒）

理由は、ルシアがまだその部屋を見つけていないからです。「こんな部屋があったらいいな」という、あるかどうか分からない物を説明するときは、que のあとが接続法になります。
反対に、もう住んでいる部屋なら、「Vivo en un piso que está cerca del centro.」と、普通の「está」を使います。
まだない物は接続法、もうある物は直説法。これだけ覚えておけば大丈夫です。

▶スライド3「覚えておきたい表現」（約55秒）

もう一つ、「No pasa nada.」も覚えておくと便利です。「大丈夫です、気にしないで」という意味で、スペインでは本当によく聞きます。
【自分のひとこと　例：私がこの表現を初めて聞いたのは〜／接続法を覚えるとき、私は〜と考えています】
では、キーフレーズを確認していきましょう。

```json
"commentary": {
  "audio": "commentary/ep01.m4a",
  "slides": [
    {"at": 0,  "title": "この回のポイント", "points": [{"es": "Estoy buscando un piso que esté cerca del centro.", "ja": "中心街の近くにある部屋を探しています"}, "está ではなく接続法の esté"]},
    {"at": 25, "title": "例文で比べる", "points": [{"es": "Busco un piso que esté cerca del centro.", "ja": "まだない部屋 → 接続法"}, {"es": "Vivo en un piso que está cerca del centro.", "ja": "もうある部屋 → 直説法"}]},
    {"at": 55, "title": "覚えておきたい表現", "points": [{"es": "No pasa nada.", "ja": "大丈夫です・気にしないで"}]}
  ]
}
```

## 長い動画2：レストランで注文の間違いを伝える（ep02）

▶スライド1「ていねいに頼む」（0秒）

今回は、レストランで注文の間違いを伝える会話でした。お店で何かを頼むとき、ていねいに言えているか緊張しますよね。
ポイントは、カルメンのこのセリフです。
「¿Me podría traer un poco más de pan?」
「パンをもう少しいただけますか？」という意味です。
「podría」は、poder の過去未来形です。「¿Puede...?」でも通じますが、「¿Podría...?」にすると、ぐっとていねいになります。日本語の「〜できますか」と「〜していただけますか」の違いに近いです。お店やホテルでは、この「¿Podría...?」を使っておけば、まず失礼になりません。

▶スライド2「たった今起きたこと」（約40秒）

もう一つは、最初のセリフ。「Creo que ha habido un error.」「間違いがあったようです」。
「ha habido」は、「hay」の現在完了です。スペインでは、今日起きたことや、たった今起きたことを、この現在完了でよく言います。

▶スライド3「事情を伝える」（約60秒）

それから、「Es que soy alérgica al marisco.」の「es que」。「実は〜なんです」と、事情を添える言い方です。アレルギーがある人は、このまま覚えておくと、旅行で本当に役に立ちます。
【自分のひとこと　例：スペインのレストランで私が困ったのは〜】
では、キーフレーズを確認しましょう。

```json
"commentary": {
  "audio": "commentary/ep02.m4a",
  "slides": [
    {"at": 0,  "title": "ていねいに頼む", "points": [{"es": "¿Me podría traer un poco más de pan?", "ja": "パンをもう少しいただけますか？"}, "¿Puede...? より ¿Podría...? のほうがていねい"]},
    {"at": 40, "title": "たった今起きたこと", "points": [{"es": "Creo que ha habido un error.", "ja": "間違いがあったようです"}, "ha habido は hay の現在完了"]},
    {"at": 60, "title": "事情を伝える", "points": [{"es": "Es que soy alérgica al marisco.", "ja": "実は魚介アレルギーなんです"}]}
  ]
}
```

## 長い動画3：友達と週末の出来事を話す（ep03）

▶スライド1「過去形は2つ」（0秒）

今回は、友達と週末の出来事を話す会話でした。過去の話をするとき、スペイン語には過去形が2つあります。点過去と線過去です。ここで迷う人は、本当に多いです。

▶スライド2「見分け方」（約15秒）

見分け方はシンプルです。「何をしたか」という出来事は点過去。「Fui a Toledo.」「トレドに行った」。
「そのときどうだったか」という状況や背景は線過去。「Hacía buen tiempo.」「天気が良かった」。

▶スライド3「1つの文で両方」（約35秒）

この2つが1つの文に入っているのが、「Mientras volvíamos en el tren, nos la comimos casi toda.」「帰りの電車の中で、ほとんど全部食べちゃった」です。
電車で帰っている、という背景が線過去の「volvíamos」。その中で起きた「食べちゃった」が、点過去の「comimos」です。
映画で言うと、線過去が背景で、点過去がその上で起きる出来事。そうイメージすると分かりやすいです。

▶スライド4「使ってみたい表現」（約65秒）

最後の「Avísame, que me apunto.」もおすすめです。「声をかけてね、私も行くから」。「apuntarse」は、誘いに乗るときによく使います。
【自分のひとこと　例：私は点過去と線過去を〜で覚えました】
では、キーフレーズで確認しましょう。

```json
"commentary": {
  "audio": "commentary/ep03.m4a",
  "slides": [
    {"at": 0,  "title": "過去形は2つ", "points": ["点過去：何をしたか（出来事）", "線過去：そのときどうだったか（状況・背景）"]},
    {"at": 15, "title": "見分け方", "points": [{"es": "Fui a Toledo.", "ja": "トレドに行った（点過去）"}, {"es": "Hacía buen tiempo.", "ja": "天気が良かった（線過去）"}]},
    {"at": 35, "title": "1つの文で両方", "points": [{"es": "Mientras volvíamos en el tren, nos la comimos casi toda.", "ja": "volvíamos＝背景（線過去）、comimos＝出来事（点過去）"}]},
    {"at": 65, "title": "使ってみたい表現", "points": [{"es": "Avísame, que me apunto.", "ja": "声をかけてね、私も行くから"}]}
  ]
}
```

## ショート動画（各10秒ほど）

ショート動画は今のところ、自分の声を入れる場所がありません（入れられるようにすることはできます）。
入れる場合は、最初のお題と最後のメモを自分の声で読む形がおすすめです。

| # | 最初（お題） | 最後（ひとこと） |
|---|---|---|
| 01 | 「それな」って、スペイン語でなんて言うと思いますか？ | 「Ya te digo」はスペインでよく使います。中南米なら「Totalmente」が安心です。 |
| 02 | 「やばい」って、スペイン語でなんて言う？ | いい意味なら「Qué pasada」、びっくりしたときは「Qué fuerte」です。 |
| 03 | 「沼る」って、スペイン語でなんて言う？ | 「enganchar」は、フックに引っかけるという意味。まさに沼ですね。 |
| 04 | 「ネタバレ」って、スペイン語でなんて言う？ | 実はスペイン語でも、英語の「spoiler」をそのまま使います。 |
| 05 | 「エモい」って、スペイン語でなんて言う？ | 「emo」と言うと別の意味になるので気をつけてください。 |
| 06 | 「草」って、スペイン語でなんて言う？ | スペイン語の j は「ハ」の音。だから笑い声は「jajaja」です。 |
